# 📖 CV 是什么？

## 🧠 定义

计算机视觉（Computer Vision, CV）是人工智能的分支，研究如何让计算机从图像和视频中 **提取信息、理解内容**，甚至 **生成新的视觉内容**。

人类用眼睛和大脑理解世界，CV 让计算机拥有"眼睛"。

---

## 🎯 应用场景

| 场景 | 说明 | 例子 |
| --- | --- | --- |
| **人脸识别** | 检测并识别人的身份 | 手机解锁、安防 |
| **自动驾驶** | 识别车道、行人、车辆、交通标志 | Tesla、Waymo |
| **医学影像** | 病灶检测、细胞分析 | CT/MRI 辅助诊断 |
| **工业质检** | 检测产品缺陷 | 生产线自动化 |
| **图像检索** | 以图搜图 | 电商拍照购物 |
| **OCR** | 识别图片中的文字 | 发票识别、证件扫描 |
| **图像生成** | 文生图、图生图 | Midjourney、美颜 |

---

## 🖼️ 计算机眼中的图像

一张图片在计算机里是 **数字矩阵**：

```
一张 32x32 的彩色图片
 = 3 个矩阵（RGB 三通道）
 = 32 × 32 × 3 个数字
```

```python
from PIL import Image
import numpy as np

img = Image.open("cat.jpg").resize((32, 32))
arr = np.array(img)
print(arr.shape)   # (32, 32, 3)  → 高、宽、通道
print(arr[0, 0])   # 第一个像素的 [R, G, B] 值
```

**关键洞察**：图像本质是数字，深度学习（尤其 CNN）擅长从这些数字中自动学习特征。

---

## 🧠 与深度学习的关系

现代 CV 几乎全部基于深度学习：

```
图像像素矩阵
  → CNN（卷积网络）自动提取特征
  → 全连接层 / 检测头 / 分割头
  → 分类结果 / 目标框 / 像素标签
```

> 💡 核心架构笔记见本站 [卷积神经网络](../DeepLearning/卷积神经网络/index.md) 章节。

---

## 🎯 小结

- CV 让计算机理解图像，应用遍及安防、医疗、自动驾驶
- 图像在计算机中是数字矩阵（高 × 宽 × 通道）
- 现代 CV = 深度学习 + 大规模数据
