# 🧩 CV 技术演进

CV 的技术发展可以概括为：从 **手工特征** 到 **自动学习**，从 **卷积网络** 到 **Transformer** 再到 **生成模型**。

---

## 📈 演进总览

| 阶段 | 代表 | 特点 |
| --- | --- | --- |
| **传统方法** | HOG、SIFT | 手工设计特征 + 分类器 |
| **CNN 时代** | LeNet、AlexNet、ResNet | 卷积自动提取特征 |
| **检测网络** | YOLO、Faster R-CNN | 端到端目标检测 |
| **Transformer** | ViT、DETR | 注意力机制进入视觉 |
| **生成模型** | GAN、扩散模型 | 图像生成、可控创作 |

---

## 🧱 一、传统方法（2012 之前）

靠人工设计特征描述图像：

- **SIFT**：尺度不变特征，用于匹配与拼接
- **HOG**：方向梯度直方图，用于行人检测
- **Haar**：用于人脸检测（早期 Viola-Jones）

```
图像 → 手工特征（SIFT/HOG/Haar）→ 分类器（SVM）→ 结果
```

**局限**：特征靠专家设计，泛化差，无法应对复杂场景。

---

## 🌀 二、CNN 时代（2012-2017）

**AlexNet**（2012）在 ImageNet 上大幅领先，深度学习全面进入 CV。

**CNN 的核心思想**：卷积核自动学习特征，无需人工设计。

| 里程碑 | 贡献 |
| --- | --- |
| **LeNet**（1998） | 最早的手写数字识别 CNN |
| **AlexNet**（2012） | 深度 CNN + ReLU + GPU，引爆深度学习 |
| **VGG**（2014） | 小卷积核堆叠，网络加深 |
| **GoogLeNet**（2014） | Inception 模块 |
| **ResNet**（2015） | 残差连接，解决深层网络退化 |

```python
# ResNet 残差块思想：学习残差 F(x)，输出 F(x) + x
# 让深层网络也能收敛
```

---

## 🎯 三、检测网络（2015-）

从"分类整图"走向"定位物体"：

| 流派 | 代表 | 特点 |
| --- | --- | --- |
| **两阶段** | Faster R-CNN、Mask R-CNN | 先提候选框再分类，精度高 |
| **单阶段** | YOLO、SSD | 一步到位，速度快 |
| **Transformer** | DETR | 端到端，无锚框 |

---

## ⚡ 四、Transformer 进入视觉（2020-）

**ViT（Vision Transformer）**：把图像切成 patch，用 Transformer 处理，不再依赖卷积。

```
图像 → 切块（patch）→ 线性映射 → Transformer 编码器 → 分类
```

| 模型 | 创新 |
| --- | --- |
| **ViT** | 纯 Transformer 做图像分类 |
| **DETR** | Transformer 做目标检测 |
| **Swin Transformer** | 分层窗口注意力，适配多尺度 |

> 💡 Transformer 原理见本站 [注意力机制](../DeepLearning/注意力机制/index.md)。

## 🎨 五、生成模型（2014-）

从"理解图像"走向"生成图像"：

| 技术 | 特点 |
| --- | --- |
| **GAN**（2014） | 生成器 vs 判别器对抗，图像逼真 |
| **VAE** | 变分自编码器，潜空间可控 |
| **扩散模型**（2020） | 逐步去噪，质量最高 |
| **文生图** | 文本引导生成（Stable Diffusion、DALL·E） |

---

## 🧠 六、两大主线

```
理解主线：分类 → 检测 → 分割 → 姿态（越来越精细）
生成主线：GAN → 扩散模型 → 可控文生图（越来越强）
```

两条主线在 **自监督预训练** 和 **大模型** 上逐渐汇合。

---

## 🎯 小结

- 传统方法靠手工特征，CNN 让特征自动学习
- 检测从两阶段走向单阶段，再到端到端 Transformer
- ViT 让视觉拥抱注意力机制
- 扩散模型开启了高质量的图像生成时代
