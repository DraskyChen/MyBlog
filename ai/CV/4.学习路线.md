# 🗺️ CV 学习路线

CV 领域广、模型多，容易迷失方向。本文给出一条从零到实战的可行路径。

---

## 🪜 总路线图

```
①图像基础 → ②CNN 原理 → ③经典架构 → ④任务实战 → ⑤进阶方向
```

---

## 📚 分阶段学习

### 阶段 1：图像基础

- 像素、颜色空间（RGB/灰度）
- 图像读取与预处理：OpenCV / PIL
- 数据增强概念

```python
# OpenCV 基础
import cv2
img = cv2.imread("cat.jpg")       # 读取
img = cv2.resize(img, (224, 224)) # 缩放
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)  # 转灰度
```

### 阶段 2：CNN 原理

理解卷积网络的核心组件，这是 CV 的基石。

- 卷积、池化、填充、步幅
- **本站配套**：[深度学习 → 卷积神经网络](../DeepLearning/卷积神经网络/index.md)

### 阶段 3：经典架构

- LeNet → AlexNet → VGG → ResNet
- **本站配套**：[深度学习 → 现代卷积神经网络](../DeepLearning/现代卷积神经网络/index.md)

### 阶段 4：任务实战

| 任务 | 入门方法 | 工具 |
| --- | --- | --- |
| 分类 | ResNet + torchvision | PyTorch |
| 检测 | YOLO | ultralytics |
| 分割 | Mask R-CNN | detectron2 |
| 人脸 | InsightFace | 专用库 |

> 💡 动手跑一个 [PyTorch](../PyTorch/index.md) 的分类实战，是入门的最佳路径。

### 阶段 5：进阶方向

| 方向 | 内容 |
| --- | --- |
| **Transformer 视觉** | ViT、Swin、DETR |
| **自监督学习** | MAE、CLIP（对比学习） |
| **图像生成** | 扩散模型、Stable Diffusion |
| **多模态** | 图文理解、视觉-语言模型 |
| **视频理解** | 动作识别、时序建模 |

---

## 💡 学习建议

1. **先分类后检测**：图像分类是基础，其他任务大多是"分类 + 定位/分割"
2. **跑通再读论文**：用 YOLO 跑一次检测，比读十篇论文更有体感
3. **善用预训练**：`pretrained=True` 加载权重，在真实任务上微调
4. **结合深度学习笔记**：本站 [深度学习](../DeepLearning/index.md) 的「计算机视觉」章节有完整实现

---

## 🎯 小结

- 主线：图像基础 → CNN → 经典架构 → 任务实战 → 进阶
- 分类是基石，检测/分割是细化
- 用预训练模型 + 微调，快速做真实项目
