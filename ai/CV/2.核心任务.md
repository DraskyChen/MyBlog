# 🎯 CV 核心任务

CV 的任务可以按"输入输出形态"分为几大类。理解任务分类，就明白一个视觉系统在解决什么问题。

---

## 📊 任务总览

| 任务 | 输入 → 输出 | 应用 |
| --- | --- | --- |
| **图像分类** | 图片 → 类别标签 | 相册分类、医学影像 |
| **目标检测** | 图片 → 多个框 + 类别 | 自动驾驶、安防 |
| **语义分割** | 图片 → 每像素类别 | 道路分割 |
| **实例分割** | 图片 → 每个物体独立掩膜 | 细胞分析 |
| **姿态估计** | 图片 → 关键点坐标 | 动作捕捉 |
| **图像生成** | 文本/噪声 → 新图片 | AIGC、美颜 |
| **图像检索** | 图片 → 相似图片 | 以图搜图 |

---

## 🔍 各任务详解

### 1. 图像分类（Classification）

判断整张图属于哪个类别：

```
输入: 一张猫的图片
输出: 猫（0.95）、狗（0.03）、鸟（0.02）
```

```python
from torchvision import models
import torch

model = models.resnet18(pretrained=True)
model.eval()
# out = model(img)  → 1000 个类别的概率分布
```

### 2. 目标检测（Object Detection）

不仅分类，还要 **定位多个物体**，输出边界框：

```
输入: 街景图片
输出: [行人 (x,y,w,h), 车辆 (x,y,w,h), ...]
```

| 代表方法 | 特点 |
| --- | --- |
| **YOLO** | 单阶段，速度快，实时检测 |
| **Faster R-CNN** | 两阶段，精度高 |
| **DETR** | 基于 Transformer 的端到端检测 |

### 3. 语义分割（Semantic Segmentation）

给 **每个像素** 打上类别标签（同一类物体不区分个体）：

```
输入: 道路图片
输出: 每个像素 → 道路/车辆/行人/天空
```

> 实例分割更进一步：每个独立物体有单独掩膜，比如"车1"和"车2"分开。

### 4. 姿态估计（Pose Estimation）

检测人体关键点（关节、脸部特征）：

```
输入: 人物图片
输出: 17 个关键点的坐标（头、肩、肘、腕、膝、踝...）
```

应用：动作捕捉、健身姿势纠正、AR 滤镜。

### 5. 图像生成（Generation）

生成全新图像，近年最火的方向：

| 技术 | 特点 |
| --- | --- |
| **GAN** | 生成器 + 判别器对抗训练 |
| **扩散模型（Diffusion）** | 从噪声逐步去噪生成，质量高 |
| **文生图** | 文本描述 → 图像（Midjourney、Stable Diffusion） |

---

## 🧠 任务间的关系

```
分类（整图一个标签）
   ↓ 更精细
检测（框出多个物体）
   ↓ 更精细
分割（像素级理解）
   ↓
实例分割 / 姿态估计（结构理解）
   ↓
生成（从理解到创作）
```

---

## 🎯 小结

- 核心任务从"整图分类"逐步细化到"像素级分割"
- 检测看 YOLO 系列，分割看 Mask R-CNN
- 生成模型（扩散模型）是当前热点
- 理解任务类型，是选模型和读论文的起点
