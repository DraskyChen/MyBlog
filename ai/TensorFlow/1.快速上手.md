# 🚀 TensorFlow 快速上手

本文用 `tf.keras` 从安装到训练，快速跑通第一个模型。

---

```bash

pip install tensorflow
```

验证：


---

## 🏗️ 二、用 tf.keras 搭建模型

### 1. Sequential 顺序模型（最简单）

```python
import tensorflow as tf

model = tf.keras.Sequential([
    tf.keras.layers.Dense(16, activation='relu', input_shape=(2,)),
    tf.keras.layers.Dense(1)
])
```

### 2. 编译

```python
model.compile(
    optimizer='adam',        # 优化器
    loss='mse',              # 损失函数
    metrics=['mae']          # 监控指标
)
```

### 3. 训练与评估

```python
# 数据
x = tf.random.normal((100, 2))
y = tf.random.normal((100, 1))

model.fit(x, y, epochs=50, batch_size=32)   # 训练
model.evaluate(x, y)                        # 评估
model.predict(x[:3])                        # 预测
```

## 📈 三、完整示例：线性回归

```python
import tensorflow as tf
import numpy as np

# 1. 数据：y = 2x + 1
x = np.linspace(0, 1, 200, dtype=np.float32).reshape(-1, 1)
y = 2 * x + 1 + 0.05 * np.random.randn(200, 1).astype(np.float32)

# 2. 模型
model = tf.keras.Sequential([tf.keras.layers.Dense(1)])
model.compile(optimizer='sgd', loss='mse')

# 3. 训练
model.fit(x, y, epochs=200, verbose=0)

# 4. 验证
w, b = model.layers[0].get_weights()
print(f"学习到: w={w[0][0]:.3f}, b={b[0]:.3f}")   # 接近 w=2, b=1
```

## 🧠 四、函数式 API（更灵活）

需要多输入、多输出或共享层时用函数式 API：

```python
inputs = tf.keras.Input(shape=(2,))
x = tf.keras.layers.Dense(16, activation='relu')(inputs)
x = tf.keras.layers.Dense(8, activation='relu')(x)
outputs = tf.keras.layers.Dense(1)(x)

model = tf.keras.Model(inputs=inputs, outputs=outputs)
```

---

## 💾 五、保存与加载

```python
# 保存整个模型
model.save("my_model.keras")

# 加载
loaded = tf.keras.models.load_model("my_model.keras")
```

---

## 🎯 小结

- `tf.keras.Sequential` 快速搭顺序模型
- `compile` + `fit` + `evaluate` 是标准流程
- 复杂结构用函数式 API
- 模型一键 `.save()` / `load_model`
