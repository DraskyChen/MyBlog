# 🗺️ TensorFlow 学习路线

TensorFlow 生态完整，从建模到部署都有成熟方案。本文给出一条从入门到生产部署的路径。

---

## 🪜 总路线图

```
①快速上手 → ②核心概念 → ③tf.keras 进阶 → ④数据与训练优化 → ⑤部署
```

---

## 📚 分阶段学习

### 阶段 1：快速上手

- [快速上手](./1.快速上手.md)：安装、`tf.keras.Sequential`、`compile`/`fit`
- 目标：跑通第一个线性回归 / 分类模型

### 阶段 2：核心概念

- [核心概念](./2.核心概念.md)：张量、Eager 模式、GradientTape、tf.data
- 理解框架底层，才能应对复杂需求

### 阶段 3：tf.keras 进阶

| 主题 | 内容 |
| --- | --- |
| 回调 | EarlyStopping、ModelCheckpoint、TensorBoard |
| 自定义层 | 继承 `tf.keras.layers.Layer` |
| 自定义训练 | GradientTape 手写训练循环 |
| 迁移学习 | 加载预训练模型微调 |

```python
# 回调示例
callbacks = [
    tf.keras.callbacks.EarlyStopping(patience=5),
    tf.keras.callbacks.ModelCheckpoint("best.keras", save_best_only=True),
    tf.keras.callbacks.TensorBoard(log_dir="./logs"),
]
model.fit(x, y, callbacks=callbacks, epochs=100)
```

### 阶段 4：数据与训练优化

- `tf.data` 高性能管道（.map / .prefetch / .cache）
- 混合精度训练、多 GPU 分布式
- 数据增强

### 阶段 5：部署（TF 的最大优势）

| 方式 | 场景 |
| --- | --- |
| **TF Serving** | 服务端高并发推理（Docker 部署） |
| **TFLite** | 移动端 / 嵌入式 / 边缘设备 |
| **TF.js** | 浏览器端推理 |
| **ONNX** | 跨框架转换 |

```python
# 导出 SavedModel（TF Serving 标准格式）
model.export("saved_model/1")
```

## 💡 学习建议

1. **先 `fit` 后深究**：用高层 API 跑通，再学底层细节
2. **部署是 TF 强项**：入门后重点练 TF Serving / TFLite
3. **原理通用**：深度学习理论见本站 [深度学习](../DeepLearning/index.md)，不绑定框架
4. **需要对比时**：看 [与 PyTorch 对比](./3.与PyTorch对比.md)
