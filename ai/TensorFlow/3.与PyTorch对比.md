# ⚖️ TensorFlow 与 PyTorch 对比

TensorFlow 与 PyTorch 是两大主流深度学习框架。本文从选型角度做完整对比。

---

## 📊 对比总览

| 维度 | TensorFlow | PyTorch |
| --- | --- | --- |
| 高层 API | tf.keras | nn.Module + Lightning |
| 部署 | TF Serving / TFLite 成熟 | TorchScript / ONNX |
| 移动端 | TFLite 优势明显 | PyTorch Mobile |
| 数据管道 | tf.data（性能强） | DataLoader（Python 灵活） |
| 计算图 | 动态（Eager）+ 静态 | 动态（默认） |
| 社区 | 生产/工业强 | 研究/学术主流 |
| NLP/大模型 | 支持（HuggingFace 也有 TF 版） | 事实标准 |

---

## 🎯 各自的优势场景

### TensorFlow 更强
- **移动端 / 嵌入式**：TFLite 优化成熟
- **服务端高并发推理**：TF Serving 久经考验
- **工业团队**：已有 TF 基础设施
- **大规模分布式训练**：历史积累深厚

### PyTorch 更强
- **研究与论文复现**：学术界绝对主流
- **NLP 与大模型**：HuggingFace 默认 PyTorch
- **快速原型**：动态图调试直观
- **动态结构**：变长序列、条件分支建模灵活

---

## 💡 选型建议

| 场景 | 推荐 |
| --- | --- |
| 学深度学习、做研究 | **PyTorch** |
| NLP / 大模型开发 | **PyTorch** |
| 移动端 App 内置模型 | **TensorFlow（TFLite）** |
| 服务端高并发推理 | TF Serving 或 ONNX Runtime |
| 企业已有 TF 基础设施 | TensorFlow |

> 💡 **两者能力相当**。学习重点是深度学习原理本身，掌握一个后，另一个很快能上手。本站深度学习笔记基于 PyTorch，[PyTorch 概览](../PyTorch/index.md) 有完整对比。

---

## 🎯 小结

- TensorFlow：生产部署、移动端、工业团队
- PyTorch：研究、NLP、大模型、快速原型
- 不必纠结"学哪个"，原理相通，按场景选型
