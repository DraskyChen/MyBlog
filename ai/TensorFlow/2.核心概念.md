# 🔧 TensorFlow 核心概念

本文梳理 TF 的核心概念：张量、Eager 模式、自动微分、数据管道，理解这些才能灵活使用框架。

---

## 🔢 一、张量（Tensor）

TF 的数据单元是 `tf.Tensor`，类似 NumPy 数组：

```python
import tensorflow as tf

# 创建
t = tf.constant([[1, 2], [3, 4]])   # 常量
z = tf.zeros((2, 3))                 # 全 0
r = tf.random.normal((2, 3))         # 随机

# 属性
print(t.shape)      # (2, 2)
print(t.dtype)      # <dtype: 'int32'>

# 运算
a = tf.constant([1., 2., 3.])
b = tf.constant([4., 5., 6.])
a + b              # [5, 7, 9]
a * b              # 逐元素乘
tf.reduce_sum(a)   # 求和

# 与 NumPy 互转
import numpy as np
arr = t.numpy()                    # Tensor → NumPy
t2 = tf.constant(np.array([1, 2])) # NumPy → Tensor
```

---

## ⚡ 二、Eager 模式（动态图）

TF 2.x **默认开启 Eager 模式**：代码一行行立即执行，像 NumPy 一样调试。

```python
x = tf.constant(2.0)
y = x ** 2 + 3 * x
print(y.numpy())   # 10.0，立即算出结果
```

> 💡 TF 1.x 的静态图需要 `tf.Session().run()`，TF 2.x 已废弃，无需再学。

## 📈 三、自动微分（GradientTape）

`tf.GradientTape` 实现自动求导，等价于 PyTorch 的 `autograd`：

```python
x = tf.Variable(2.0)          # 可训练变量

with tf.GradientTape() as tape:
    y = x ** 2 + 3 * x        # y = x² + 3x

dy_dx = tape.gradient(y, x)
print(dy_dx.numpy())          # 7.0 = 2x + 3
```

**自定义训练循环**：

```python
optimizer = tf.keras.optimizers.SGD(learning_rate=0.01)

with tf.GradientTape() as tape:
    pred = model(x)
    loss = tf.keras.losses.mse(y_true, pred)

grads = tape.gradient(loss, model.trainable_variables)
optimizer.apply_gradients(zip(grads, model.trainable_variables))
```

> 💡 用 `model.fit` 时框架自动处理梯度，无需手写；自定义循环才用 GradientTape。

## 📥 四、数据管道（tf.data）

`tf.data.Dataset` 提供高性能数据加载：

```python
# 从数组
dataset = tf.data.Dataset.from_tensor_slices((x, y))

# 从文件列表
dataset = tf.data.Dataset.list_files("images/*.jpg")

# 管道操作
dataset = (
    dataset
    .shuffle(1000)            # 打乱
    .batch(32)                # 分批
    .map(preprocess)          # 预处理
    .prefetch(tf.data.AUTOTUNE)  # 预取加速
)

model.fit(dataset, epochs=10)
```

| 操作 | 作用 |
| --- | --- |
| `.shuffle(n)` | 打乱数据 |
| `.batch(n)` | 分批 |
| `.map(fn)` | 逐样本处理（增强、归一化） |
| `.prefetch()` | 预取，重叠 CPU/GPU 计算 |

## 🧠 五、Variables 与 Checkpoint

```python
# 可训练变量
w = tf.Variable(tf.random.normal([2, 1]))

# 保存/恢复
checkpoint = tf.train.Checkpoint(model=model)
checkpoint.save("ckpt/model")          # 保存
checkpoint.restore("ckpt/model")       # 恢复
```

---

## 🎯 小结

- 张量是数据单元，Eager 模式让调试像 NumPy
- `GradientTape` 负责自动微分
- `tf.data.Dataset` 管理高性能数据管道
- 日常用 `model.fit`，自定义循环才用 GradientTape
