# 🔢 PyTorch 张量基础

张量（Tensor）是 PyTorch 的数据核心，类似 NumPy 数组但支持 **GPU 加速** 和 **自动求导**。

---

## 📦 一、创建张量

```python
import torch

# 从数据
t = torch.tensor([[1, 2], [3, 4]])   # 形状 (2, 2)

# 常用初始化
z = torch.zeros(2, 3)                # 全 0
o = torch.ones(2, 2)                 # 全 1
e = torch.eye(3)                     # 单位矩阵
r = torch.randn(2, 3)                # 标准正态随机
a = torch.arange(5)                  # [0, 1, 2, 3, 4]
```

---

## 🔍 二、基本属性与操作

```python
# 属性
print(t.shape)      # torch.Size([2, 2])
print(t.dtype)      # torch.int64
print(t.device)     # cpu / cuda

# 变形
t.reshape(-1)              # 展平为 [1,2,3,4]
t.view(4, 1)               # 变 (4, 1)，要求内存连续
t.permute(1, 0)            # 交换维度（转置）

# 运算
a = torch.tensor([1., 2., 3.])
b = torch.tensor([4., 5., 6.])
a + b                      # [5, 7, 9]
a * b                      # 逐元素乘
a.sum()                    # 求和（标量）
a.mean()                   # 均值
a.max()                    # 最大值

# 索引与切片
a[0]                       # 1.0
t[:, 0]                    # 第一列
```

> 💡 `reshape` 与 `view`：`reshape` 更灵活（不要求连续内存），初学用 `reshape` 即可。

---

## 🔄 三、广播机制（Broadcasting）

形状不匹配时，PyTorch 自动扩展较小的张量：

```python
x = torch.arange(3)          # 形状 (3,)       [0, 1, 2]
y = torch.tensor([[1], [2]]) # 形状 (2, 1)
print(x + y)                 # 形状 (2, 3)
# [[1, 2, 3],
#  [2, 3, 4]]
```

**规则**：从尾部维度对齐，一个为 1 或相等即可广播。

```python
# 广播也用于标量运算
t * 2          # 每个元素乘 2
t + 1.0        # 每个元素加 1
```

## ⚙️ 四、设备切换（CPU / GPU）

```python
t = torch.randn(2, 2)

t = t.to("cuda")    # 移到 GPU
t = t.cpu()         # 移回 CPU

# 检查设备
print(t.device)                 # cuda:0 / cpu
print(torch.cuda.is_available()) # GPU 是否可用
```

> 💡 训练大型模型时，模型和数据都要在 GPU 上：`model.to("cuda")` + `x.to("cuda")`。

---

## 🧮 五、与 NumPy 互转

```python
import numpy as np

# NumPy → Tensor
arr = np.array([[1, 2], [3, 4]])
t = torch.from_numpy(arr)

# Tensor → NumPy
arr_back = t.numpy()
```

> ⚠️ 默认共享内存，修改一个会影响另一个。需要独立副本时用 `.clone()` / `.copy()`。

## 🎯 小结

- 创建：`tensor` / `zeros` / `ones` / `randn` / `arange`
- 属性：`shape` / `dtype` / `device`
- 广播机制让不同形状也能运算
- 训练前把数据 `.to("cuda")` 移到 GPU
