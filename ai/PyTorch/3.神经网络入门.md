# 🧠 PyTorch 神经网络入门

掌握张量和自动求导后，本文带你用 `nn.Module` 搭建并训练第一个神经网络。

---

## 🧱 一、nn.Module：模型的基类

所有神经网络都继承 `nn.Module`：

```python
import torch
import torch.nn as nn

class MyModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.linear1 = nn.Linear(2, 16)   # 输入 2 维 → 16 维
        self.relu = nn.ReLU()             # 激活函数
        self.linear2 = nn.Linear(16, 1)   # 16 维 → 输出 1 维

    def forward(self, x):
        x = self.linear1(x)
        x = self.relu(x)
        x = self.linear2(x)
        return x

model = MyModel()
print(model)
# MyModel(
#   (linear1): Linear(in_features=2, out_features=16, bias=True)
#   (relu): ReLU()
#   (linear2): Linear(in_features=16, out_features=1, bias=True)
# )
```

**要点**：
- 层定义在 `__init__` 中
- 前向计算写在 `forward` 中（**不需要手动调用**，调用 `model(x)` 会触发）

## 🧩 二、常用层与激活函数

| 组件 | 作用 | 用法 |
| --- | --- | --- |
| `nn.Linear(in, out)` | 全连接层 | `nn.Linear(784, 10)` |
| `nn.ReLU()` | 线性整流激活 | `nn.ReLU()` |
| `nn.Sigmoid()` | 二分类激活 | `nn.Sigmoid()` |
| `nn.Softmax(dim)` | 多分类概率 | `nn.Softmax(dim=1)` |
| `nn.Dropout(p)` | 随机丢弃防过拟合 | `nn.Dropout(0.2)` |
| `nn.Conv2d(...)` | 卷积层 | `nn.Conv2d(3, 16, 3, padding=1)` |
| `nn.MaxPool2d(...)` | 池化层 | `nn.MaxPool2d(2)` |

## 📈 三、损失函数与优化器

```python
# 回归任务
loss_fn = nn.MSELoss()          # 均方误差

# 二分类
loss_fn = nn.BCEWithLogitsLoss()

# 多分类
loss_fn = nn.CrossEntropyLoss()

# 优化器
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
optimizer = torch.optim.SGD(model.parameters(), lr=0.01, momentum=0.9)
```

> 💡 常用组合：分类用 `CrossEntropyLoss` + Adam；回归用 `MSELoss` + SGD/Adam。

## 🔄 四、数据加载：Dataset 与 DataLoader

```python
from torch.utils.data import Dataset, DataLoader

class MyDataset(Dataset):
    def __init__(self, xs, ys):
        self.xs = xs
        self.ys = ys

    def __len__(self):
        return len(self.xs)

    def __getitem__(self, idx):
        return self.xs[idx], self.ys[idx]

dataset = MyDataset(xs, ys)
loader = DataLoader(dataset, batch_size=32, shuffle=True)
```

**DataLoader 的好处**：
- 自动 **分批（batch）** 训练
- `shuffle=True` 打乱数据
- 支持多进程并行加载

## 🏋️ 五、完整训练循环（线性回归）

```python
import torch
import torch.nn as nn
from torch.utils.data import DataLoader, TensorDataset

# 1. 数据：y = 2x + 1
x = torch.linspace(0, 1, 200).reshape(-1, 1)
y = 2 * x + 1 + 0.05 * torch.randn_like(x)
loader = DataLoader(TensorDataset(x, y), batch_size=32, shuffle=True)

# 2. 模型 + 损失 + 优化器
model = nn.Linear(1, 1)
loss_fn = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

# 3. 训练
for epoch in range(50):
    for xb, yb in loader:
        optimizer.zero_grad()
        pred = model(xb)
        loss = loss_fn(pred, yb)
        loss.backward()
        optimizer.step()
    if epoch % 10 == 0:
        print(f"epoch {epoch}, loss = {loss.item():.4f}")

# 4. 验证
w, b = model.weight.item(), model.bias.item()
print(f"学习到: w={w:.3f}, b={b:.3f}")   # 接近 w=2, b=1
```

## 🎯 小结

- `nn.Module`：继承并实现 `forward`
- 层 + 激活 + 损失 + 优化器 = 模型基本盘
- `DataLoader` 管理分批训练
- 训练循环：zero_grad → forward → loss → backward → step
