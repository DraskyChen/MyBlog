# ⚖️ PyTorch 与 TensorFlow 对比

PyTorch 和 TensorFlow 是深度学习领域的两大主流框架，各有侧重。本文帮你做选型决策。

---

## 📊 对比总览

| 维度 | PyTorch | TensorFlow |
| --- | --- | --- |
| 计算图 | 动态（默认，Eager） | 动态 + 静态（TF Graph） |
| 调试 | 直观（Python 原生堆栈） | 相对复杂 |
| 高层 API | nn.Module + Lightning | tf.keras |
| 数据加载 | DataLoader（Python 灵活） | tf.data（性能强） |
| 移动端 | PyTorch Mobile | **TFLite（更成熟）** |
| 服务端部署 | TorchScript / ONNX | **TF Serving（更成熟）** |
| API 稳定性 | 稳定 | 版本间变动较大 |
| 社区 | 研究/学术主流 | 工业/生产生态完整 |

---

## 🎯 各自的优势场景

### PyTorch 更强
- **研究与论文复现**：学术界主流，新模型几乎都先出 PyTorch 版
- **NLP 与大模型**：HuggingFace 默认基于 PyTorch
- **快速原型**：动态图调试方便，Python 习惯无缝迁移
- **动态结构**：变长序列、条件分支等灵活建模

### TensorFlow 更强
- **生产部署**：TF Serving、TF Lite、TF.js 生态完整
- **移动端 / 嵌入式**：TFLite 优化成熟
- **大规模分布式训练**：TF 的历史积累深厚
- **团队标准化**：工业团队已有 TF 基础设施

---

## 💡 选型建议

| 你的场景 | 推荐 |
| --- | --- |
| 学深度学习、做研究 | **PyTorch** |
| NLP / 大模型开发 | **PyTorch** |
| 移动端 App 内置模型 | **TensorFlow（TFLite）** |
| 服务端高并发推理 | TensorFlow Serving 或 ONNX Runtime |
| 企业已有 TF 基础设施 | TensorFlow |

> 💡 **两者能力相当**，学习重点应放在深度学习原理本身，而不是纠结框架。会了一个，另一个很快能上手。

---

## 🔄 迁移视角：同一模型两种写法

```python
# PyTorch
import torch.nn as nn

class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc = nn.Linear(2, 1)
    def forward(self, x):
        return self.fc(x)
```

```python
# TensorFlow (Keras)
import tensorflow as tf

model = tf.keras.Sequential([
    tf.keras.layers.Dense(1, input_shape=(2,))
])
```

两者都遵循"定义层 → 前向 → 损失 → 优化"的相同范式。

## 🎯 小结

- PyTorch：研究、NLP、大模型、动态建模
- TensorFlow：生产部署、移动端、工业团队
- 学习上不必二选一，掌握原理即可快速迁移
