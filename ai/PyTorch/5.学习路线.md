# 🗺️ PyTorch 学习路线

PyTorch 上手快，但进阶内容多。本文给出一条从零到实战的清晰路径。

---

## 🪜 总路线图

```
①张量 → ②自动求导 → ③nn.Module → ④训练实战 → ⑤经典架构 → ⑥工程化
```

---

## 📚 分阶段学习

### 阶段 1：张量基础

- [张量基础](./1.张量基础.md)：创建、运算、广播、设备
- 目标是"像用 NumPy 一样操作数据"

### 阶段 2：自动求导

- [自动求导](./2.自动求导.md)：`requires_grad`、`backward()`、计算图
- 理解训练的原理，四步套路（zero_grad → forward → backward → step）

### 阶段 3：神经网络入门

- [神经网络入门](./3.神经网络入门.md)：`nn.Module`、常用层、`DataLoader`
- 跑通第一个线性回归 / 分类模型

### 阶段 4：训练实战

- 完整训练流程：数据加载 → 模型 → 损失 → 优化 → 评估
- 手写 MNIST / CIFAR 分类
- 学习调参：学习率、batch size、正则化

### 阶段 6：工程化

## 💡 学习建议

1. **先跑通再理解**：把示例代码跑起来，再读原理
2. **动手改代码**：改学习率、改层数，看效果变化
3. **边学边记**：结合本博客 [深度学习](../DeepLearning/index.md) 笔记，理论 + 代码对照
4. **别死磕框架**：重点是深度学习原理，框架只是工具
