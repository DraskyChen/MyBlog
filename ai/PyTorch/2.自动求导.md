# 🧮 PyTorch 自动求导（autograd）

深度学习训练的核心是 **反向传播求梯度**。PyTorch 的 `autograd` 自动完成这一切——你只需要定义前向计算，梯度会自动算好。

---

## 🎯 一、核心概念

| 概念 | 说明 |
| --- | --- |
| **requires_grad** | 开启张量的梯度追踪 |
| **计算图** | 记录运算过程，用于反向传播 |
| **backward()** | 反向传播，计算梯度 |
| **grad** | 计算得到的梯度值 |

---

## 📐 二、最小示例

```python
import torch

# requires_grad=True 开启梯度追踪
x = torch.tensor(2.0, requires_grad=True)

# 定义函数 y = x² + 3x
y = x ** 2 + 3 * x

# 反向传播：计算 dy/dx
y.backward()

# 查看梯度：dy/dx = 2x + 3 = 7
print(x.grad)   # tensor(7.)
```

**过程拆解**：

```
x = 2.0 (requires_grad)
y = x² + 3x = 4 + 6 = 10
dy/dx = 2x + 3 = 7    ← backward() 自动算出
```

## 🧱 三、多变量与链式法则

```python
x1 = torch.tensor(2.0, requires_grad=True)
x2 = torch.tensor(3.0, requires_grad=True)

y = x1 ** 2 + x2 ** 3      # y = x1² + x2³
y.backward()

print(x1.grad)   # dy/dx1 = 2·x1 = 4
print(x2.grad)   # dy/dx2 = 3·x2² = 27
```

**链式法则**：复合函数逐层求导并相乘，autograd 自动按计算图回溯。

---

## 🔄 四、训练中的关键操作

### zero_grad：为什么每次要清空梯度？

梯度默认是 **累加** 的：

```python
x = torch.tensor(2.0, requires_grad=True)
y = x ** 2
y.backward()
y.backward()

print(x.grad)   # tensor(8.)   ← 累加了两次 dy/dx = 4+4
```

所以训练循环里必须先清空：

```python
optimizer.zero_grad()   # 或 model.zero_grad()
loss.backward()
optimizer.step()
```

### no_grad：推理时关闭梯度

```python
with torch.no_grad():
    pred = model(x)     # 不构建计算图，省内存更快
```

## 🤖 五、神经网络训练完整示意

```python
import torch.nn as nn

# 单层线性模型：y = wx + b
model = nn.Linear(1, 1)
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
loss_fn = nn.MSELoss()

# 训练数据 y_true = 2x
x = torch.tensor([[1.0], [2.0], [3.0]])
y_true = torch.tensor([[2.0], [4.0], [6.0]])

for _ in range(100):
    optimizer.zero_grad()          # 1. 清空梯度
    pred = model(x)                # 2. 前向计算
    loss = loss_fn(pred, y_true)   #    计算损失
    loss.backward()                # 3. 反向传播
    optimizer.step()               # 4. 更新参数

print(model(torch.tensor([[4.0]])).item())  # 接近 8
```

**四步套路**：

| 步骤 | 作用 |
| --- | --- |
| `zero_grad()` | 清空上次梯度（防累加） |
| `forward` | 前向计算预测值和损失 |
| `backward()` | 反向传播，算出每个参数梯度 |
| `step()` | 优化器按梯度更新参数 |

---

## 🎯 小结

- `requires_grad` 开启追踪，`backward()` 自动算梯度
- 梯度默认累加，训练前必须 `zero_grad()`
- 推理用 `no_grad()` 省内存
- 训练四步：zero_grad → forward → backward → step
