# 🔗 LangChain 笔记

LangChain 是构建 LLM 应用最流行的开源框架之一，用标准化的 **组件** 把模型、提示词、工具、记忆、检索串成完整应用。

---

## 🧩 一、核心组件

| 组件 | 作用 |
| --- | --- |
| **Model** | 统一接入各家 LLM（OpenAI、Anthropic、本地模型） |
| **Prompt** | 结构化提示词模板 |
| **Chain / Graph** | 串联多步处理流程 |
| **Tool** | 让模型调用外部能力 |
| **Memory** | 对话记忆、短期/长期 |
| **Retriever** | RAG 检索：向量库 + Embedding |

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate

# 模型 + 提示词
model = ChatOpenAI(model="gpt-4o-mini")
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是专业的 {role}。"),
    ("human", "{question}"),
])

# 组成链
chain = prompt | model
result = chain.invoke({"role": "Python 工程师", "question": "如何用协程?"})
print(result.content)
```

## 🧠 二、LCEL：LangChain 表达式语言

用 `|` 管道把组件组合成链，可读又灵活：

```python
chain = (
    prompt
    | model
    | StrOutputParser()      # 解析输出
    | RunnableLambda(log)    # 自定义步骤
)
```

## 📚 三、RAG 示例（检索增强生成）

```python
from langchain_community.document_loaders import TextLoader
from langchain_text_splitters import CharacterTextSplitter
from langchain_openai import OpenAIEmbeddings
from langchain_community.vectorstores import FAISS
from langchain_core.runnables import RunnablePassthrough

# 1. 加载并切分文档
docs = TextLoader("notes.txt").load()
chunks = CharacterTextSplitter(chunk_size=200, chunk_overlap=50).split_documents(docs)

# 2. 向量化存储
vectorstore = FAISS.from_documents(chunks, OpenAIEmbeddings())

# 3. 检索 + 问答
retriever = vectorstore.as_retriever()
prompt = ChatPromptTemplate.from_template(
    "基于以下资料回答问题：\n{context}\n\n问题：{question}"
)

rag_chain = (
    {"context": retriever, "question": RunnablePassthrough()}
    | prompt
    | model
    | StrOutputParser()
)
print(rag_chain.invoke("笔记里讲了什么？"))
```

## 🛠️ 四、进阶：Agent 与 LangGraph

- **LangChain 传统 Agent**：ReAct 工具调用循环
- **LangGraph**：新一代，用图结构编排复杂状态机（更可控）

```python
from langgraph.prebuilt import create_react_agent

agent = create_react_agent(model, tools=[weather_tool])
result = agent.invoke({"messages": [("user", "北京天气？")]})
```

## 🎯 五、小结

- LangChain 用组件化方式组装 LLM 应用：Prompt + Model + Chain
- LCEL 管道语法（`|`）让流程清晰
- RAG 三件套：切分 → 向量化 → 检索问答
- 复杂多步流程推荐 LangGraph
