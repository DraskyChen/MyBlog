# 🛠️ Agent 实战入门

上一页 [AI Agent 简介](./index.md) 介绍了 Agent 的概念。本文聚焦 **怎么把 Agent 跑起来**：用代码实现一个能调用工具完成任务的智能体。

---

## 🧱 一、最小 Agent 骨架

一个最简 Agent = **LLM + 工具函数 + 循环**：

```python
# 使用 OpenAI 兼容接口 + 函数调用
import json
from openai import OpenAI

client = OpenAI()

# 1. 定义工具
def get_weather(city: str) -> str:
    return f"{city} 的天气：晴，26℃"

tools = [{
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "查询城市天气",
        "parameters": {
            "type": "object",
            "properties": {
                "city": {"type": "string"}
            },
            "required": ["city"]
        }
    }
}]

# 2. 对话循环
messages = [{"role": "user", "content": "北京今天天气如何？"}]

for _ in range(5):
    resp = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=messages,
        tools=tools,
    )
    msg = resp.choices[0].message
    messages.append(msg.model_dump())

    # 3. 需要调用工具时执行并回填结果
    if msg.tool_calls:
        for call in msg.tool_calls:
            result = get_weather(json.loads(call.function.arguments)["city"])
            messages.append({
                "role": "tool",
                "tool_call_id": call.id,
                "content": result,
            })
        continue  # 拿到工具结果后继续让模型作答

    print(msg.content)
    break
```

## 🔁 二、Agent 的核心循环（ReAct）

```
Thought: 用户想知道天气，我需要调用天气工具
Action: get_weather(city="北京")
Observation: 北京 的天气：晴，26℃
Thought: 现在我有了结果，可以回答用户
Final Answer: 北京今天晴，26℃，适合出行。
```

实现要点：

| 步骤 | 说明 |
| --- | --- |
| **Observe** | 观察用户输入或工具返回 |
| **Think** | 模型推理下一步该做什么 |
| **Act** | 调用工具 / 输出中间结果 |
| **Loop** | 直到得到最终答案或达到最大轮数 |

## 🧩 三、常见工具类型

| 工具 | 场景 |
| --- | --- |
| **搜索** | 联网查询最新信息 |
| **代码执行** | 计算、数据分析（Sandbox 中） |
| **数据库查询** | 企业数据问答 |
| **HTTP API** | 对接业务系统 |
| **文件读写** | 生成报告、处理文档 |

> ⚠️ 安全提醒：工具调用要加权限控制和沙箱，避免 Agent 执行危险操作。

## 🛠️ 四、开发框架选择

| 框架 | 特点 |
| --- | --- |
| **OpenAI Function Calling** | 原生、简单、可控 |
| **LangChain / LangGraph** | 生态丰富，支持复杂工作流 |
| **Anthropic Claude + MCP** | 统一工具协议，接入高效 |
| **CrewAI** | 多 Agent 协作框架 |

---

## 🎯 五、小结

- Agent = LLM + 工具 + 循环，核心是"观察-思考-行动"
- Function Calling 让模型能调用真实工具
- 从最小骨架开始，再引入框架和 MCP 标准化接入

> 💡 工具接入的标准化方案见 [3.MCP通信协议](./3.MCP通信协议.md)。
