# 📖 NLP 是什么？

## 🧠 定义

NLP（Natural Language Processing，自然语言处理）是人工智能与语言学交叉的学科，研究如何让计算机 **处理、理解并生成** 人类语言。

**核心问题**：人类的自然语言充满歧义、省略和语境依赖，计算机需要把非结构化的文本/语音，转化为可计算的结构化表示。

```python
# 一条文本，人类秒懂，机器需要"理解"
text = "苹果发布了新款手机，它这次主打 AI 摄影"
# 这里的"它"指代谁？"苹果"是水果还是公司？—— 这就是 NLP 要解决的歧义
```

---

## 🎯 应用场景

| 场景 | 说明 | 典型产品 |
| --- | --- | --- |
| **智能搜索** | 理解查询意图，返回相关内容 | Google、百度 |
| **机器翻译** | 跨语言自动翻译 | Google 翻译、DeepL |
| **智能客服** | 自动回答用户问题 | 各类 Chatbot |
| **情感分析** | 判断文本情绪倾向 | 舆情监控、评论分析 |
| **文本摘要** | 长文自动概括 | 新闻摘要、会议纪要 |
| **语音助手** | 语音识别 + 语义理解 + 生成 | Siri、小爱同学 |
| **OCR 后处理** | 识别图片中的文字并理解 | 扫描王、发票识别 |

---

## 💡 与 LLM 的关系

大语言模型（LLM，如 GPT、Claude）本质上是 NLP 技术发展到 **大模型时代** 的产物：

```
传统 NLP：每个任务单独建模（翻译一个模型、情感一个模型）
大模型 NLP：一个通用模型，通过对话/提示词完成所有任务
```

所以理解 NLP 基础，是理解现代大模型应用的前提。

---

## 🎯 小结

- NLP 让计算机理解人类语言，解决歧义、理解、生成问题
- 应用广泛：搜索、翻译、客服、情感分析、语音助手
- 现代 LLM 是 NLP 技术演进的最新形态
