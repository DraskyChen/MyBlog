# 🗂️ NLP 任务分类

NLP 的任务可以按"输入输出形态"分为几大类。理解了任务分类，你就知道一个 NLP 系统到底在解决什么问题。

---

## 📊 五大类任务

| 任务类型 | 输入 → 输出 | 示例 |
| --- | --- | --- |
| **文本分类** | 文本 → 标签 | 情感分析、垃圾邮件识别、新闻分类 |
| **序列标注** | 文本 → 每个词的标签 | 命名实体识别（NER）、分词、词性标注 |
| **文本生成** | 文本/提示 → 新文本 | 摘要、机器翻译、对话 |
| **语义匹配** | 两段文本 → 相似度 | 问答匹配、文本查重、推荐 |
| **信息抽取** | 文本 → 结构化数据 | 关系抽取、事件抽取、知识图谱构建 |

---

## 🔍 各任务详解

### 1. 文本分类（Classification）

给整段文本打一个或多个标签。

```python
# 情感分析
text = "这家店的东西太好吃了！"
# 输出: POSITIVE
```

- **情感分析**：好评/差评
- **主题分类**：体育/财经/娱乐
- **意图识别**：订机票/查天气/开灯

### 2. 序列标注（Sequence Labeling）

给文本中的 **每个词/字** 打标签。

```
"小明在北京大学读书"
 → 小/明(PER) 在(O) 北/京/大/学(ORG) 读/书(O)
PER=人名  ORG=机构名  O=无关
```

- **命名实体识别（NER）**：识别人名、地名、机构名
- **词性标注（POS）**：名词/动词/形容词
- **中文分词**：字 → 词

### 3. 文本生成（Generation）

根据输入生成新文本，是现代大模型的核心能力。

```python
# 翻译
"Hello world" → "你好，世界"
# 摘要
长文 → "本文主要介绍了..."
# 对话
用户问题 → 助手回复
```

- **机器翻译**：跨语言生成
- **文本摘要**：抽取式 / 生成式
- **对话系统**：开放域 / 任务型

### 4. 语义匹配（Semantic Matching）

计算两段文本的语义相似度。

```python
q1 = "今天天气怎么样"
q2 = "明天会下雨吗"
# 相似度: 较高（都是天气问题）
```

- **问答系统**：问题和答案匹配
- **文本检索**：查询和文档匹配
- **句子相似度**：去重、推荐

### 5. 信息抽取（Information Extraction）

从非结构化文本中抽取结构化三元组。

```
"小明出生于北京"
 → (小明, 出生地, 北京)
```

- **关系抽取**：实体间关系
- **事件抽取**：时间、地点、人物、事件
- **知识图谱**：三元组构成图结构

---

## 🧠 任务间的关系

```
信息抽取 / 标注
   ↓ 提供结构化输入
语义匹配 / 文本分类（判别式任务）
   ↓
文本生成（生成式任务，大模型主力）
```

> 💡 现代大模型用"生成"统一了大部分任务——分类、标注也能通过提示词生成实现。

---

## 🎯 小结

- NLP 五大类：分类、标注、生成、匹配、抽取
- 传统上各任务独立建模，大模型时代趋向统一生成
- 理解任务分类，是阅读论文和选型的起点
