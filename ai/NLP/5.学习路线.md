# 🗺️ NLP 学习路线

NLP 内容多、演进快，容易迷失方向。本文给出一条从零到实战的可行路径，并标注本站配套资源。

---

## 🪜 总路线图

```
①语言基础 ─→ ②词向量 ─→ ③序列模型 ─→ ④注意力/Transformer
                                              ↓
                                   ⑤预训练模型（BERT/GPT）
                                              ↓
                                   ⑥实战框架 + 大模型应用
```

---

## 📚 分阶段学习

### 阶段 1：语言基础（选学）

了解 NLP 面对的原始问题，不深究传统算法也可。

- 分词、词性、句法（大致了解概念）
- 语料与评价指标（BLEU、F1、困惑度）

### 阶段 2：词向量

理解"词如何变成向量"。

- Word2Vec（CBOW / Skip-gram）
- GloVe
- **本站配套**：[深度学习 → 自然语言处理：预训练](../DeepLearning/自然语言处理：预训练/index.md) 的 word2vec 章节

### 阶段 3：序列模型

理解序列如何被建模。

- RNN、LSTM、GRU
- Seq2Seq（编码器-解码器）
- **本站配套**：[深度学习 → 循环神经网络](../DeepLearning/循环神经网络/index.md)

### 阶段 4：注意力与 Transformer（重点）

这是现代 NLP 的基石，务必学透。

- 注意力机制、多头注意力
- Transformer 架构
- **本站配套**：[深度学习 → 注意力机制](../DeepLearning/注意力机制/index.md)

### 阶段 5：预训练模型

理解 BERT 与 GPT 两大流派。

- BERT：掩码语言模型（编码器）
- GPT：自回归语言模型（解码器）
- **本站配套**：[深度学习 → NLP 预训练](../DeepLearning/自然语言处理：预训练/index.md)

### 阶段 6：实战与进阶

动手做项目，跟上大模型浪潮。

- **框架**：HuggingFace Transformers、LangChain
- **任务实战**：情感分析、NER、问答系统
- **大模型**：Prompt、RAG、Fine-tuning、Agent
- **本站配套**：[LLM / Agent](../LLM/Agent/index.md)

## 💡 学习建议

1. **先跑通再深究**：用 HuggingFace 跑一个情感分析，比读十篇论文更有体感
2. **抓住主线**：任何新模型，先问"它在 Transformer 基础上改了什么"
3. **跟上大模型**：传统 NLP 任务大多可被大模型 + 提示词解决，不必死磕老方法
4. **动手写**：本站 [与深度学习的关系](./4.与深度学习的关系.md) 里的代码都可以直接跑

---

## 🎯 小结

- 学习主线：词向量 → 序列模型 → Transformer → 预训练 → 大模型
- Transformer 是核心，值得花最多时间
- 用 HuggingFace 动手实践，效率最高
