# 🧩 NLP 技术演进

NLP 在过去二十年经历了多次范式跃迁，理解这条演进线，就能明白为什么大模型长成今天这样。

---

## 📈 演进总览

| 阶段 | 代表技术 | 特点 | 局限 |
| --- | --- | --- | --- |
| **词袋时代** | TF-IDF、N-gram | 把文本变成向量，简单高效 | 忽略词序，无语义 |
| **词向量时代** | Word2Vec、GloVe | 词 → 稠密向量，捕获相似语义 | 一词一义，无上下文 |
| **RNN 时代** | LSTM、Seq2Seq、注意力 | 按顺序处理序列，能建模上下文 | 难并行、长距离遗忘 |
| **Transformer 时代** | BERT、GPT | 自注意力，全序列并行 | 计算量大，需要预训练 |
| **大模型时代** | GPT-4、LLaMA | 海量预训练 + 指令微调 + 涌现 | 成本高、对齐难 |

---

## 🌾 一、词袋时代（2000s）

把文档表示成"词出现次数"的向量，词与词互相独立。

```python
from sklearn.feature_extraction.text import TfidfVectorizer

texts = ["我喜欢猫", "猫很可爱", "今天下雨"]
vec = TfidfVectorizer().fit_transform(texts)
# 每个词是一个维度，顺序信息丢失
```

**局限**：`"猫咬人"` 和 `"人咬猫"` 的向量几乎一样。

---

## 🧪 二、词向量时代（2013）

**Word2Vec / GloVe** 把每个词映射为稠密向量，让语义相近的词距离更近。

```python
# word2vec 中: king - man + woman ≈ queen
# 向量捕获了词之间的语义关系
```

```python
from gensim.models import Word2Vec
model = Word2Vec(sentences, vector_size=100, window=5, min_count=1)
model.wv.most_similar("猫")
# [("喵", 0.85), ("宠物", 0.79), ...]
```

**局限**：一个词只有一个向量，无法区分多义词（"苹果"公司 vs 水果）。

---

## 🔁 三、RNN 时代（2014-2017）

**RNN/LSTM** 按顺序读入序列，每个时间步融合历史信息，解决了一词一义的问题。

```python
# LSTM 按顺序处理每个词，隐藏状态携带上文信息
lstm = nn.LSTM(input_size, hidden_size, batch_first=True)
out, (h, c) = lstm(embedding_sequences)
```

**里程碑**：**Seq2Seq + 注意力**（Bahdanau 2015）让机器翻译取得突破。

**局限**：
- 必须按顺序计算，**难以并行**，训练慢
- 长序列中早期信息逐渐丢失（梯度消失）

---

## ⚡ 四、Transformer 时代（2017-）

**自注意力（Self-Attention）** 让序列中任意两个位置直接交互，彻底解决并行和长距离依赖问题。

```python
# Transformer 核心：注意力打分 + 加权求和
# Q(查询), K(键), V(值)
attn = softmax(Q @ K.T / sqrt(d_k)) @ V
```

- **2017**：Transformer 论文发布（Attention Is All You Need）
- **2018**：**BERT**（编码器预训练）、**GPT**（解码器预训练）
- 此后 NLP 全面进入"预训练 + 微调"范式

> 📖 技术细节见本站 [注意力机制](../DeepLearning/注意力机制/index.md) 章节。

---

## 🚀 五、大模型时代（2020-）

**Scaling Law**：模型参数、数据量、计算量一起放大，能力持续涌现。

```
预训练（海量文本，自监督）
   ↓
指令微调（教模型遵循指令）
   ↓
RLHF / 偏好对齐（让输出符合人类偏好）
   ↓
工具调用 / Agent（从"问答"到"行动"）
```

**关键变化**：
- 一个模型统一所有任务（通过提示词而非重新训练）
- 涌现能力（in-context learning、推理、代码）
- 从 NLP 扩展到多模态（文本、图像、音频）

---

## 🎯 小结

- 演进主线：**表征能力** 的提升 + **并行能力** 的提升
- 词向量 → RNN → Transformer，一步步让模型"看得更全、算得更快"
- 大模型 = Transformer + 海量数据 + 对齐技术
