# 🖥️ 后端开发

后端负责"看不见的部分"：处理业务逻辑、存储数据、提供 API 给前端和 App 调用。如果把网站比作餐厅，前端是门面，后端就是后厨。

## 🎯 一、后端的主要职责

| 职责 | 说明 |
| --- | --- |
| 业务逻辑 | 处理用户请求的核心规则 |
| 数据存储 | 读写数据库，保证一致性 |
| 接口提供 | 通过 REST / GraphQL 等暴露 API |
| 安全认证 | 登录、鉴权、权限控制 |
| 性能与扩展 | 缓存、异步、负载均衡、分布式 |

---

## 🗺️ 二、学习路线

1. **一门语言**：Java 或 Python（推荐先深入一门）
2. **数据库**：SQL 基础 + MySQL 实战
3. **Web 框架**：Spring Boot / Flask / FastAPI
4. **工程实践**：缓存（Redis）、消息队列、部署上线
5. **进阶**：微服务、容器化（K8s）、云原生
