# 📄 NoSQL 数据库

NoSQL（Not Only SQL）是非关系型数据库的统称，以 **灵活的数据模型** 和 **水平扩展** 见长，适合海量数据和高并发场景。

---

## 🧠 一、NoSQL 的四大类型

| 类型 | 代表 | 数据模型 | 典型场景 |
| --- | --- | --- | --- |
| **文档型** | MongoDB | JSON 文档 | 灵活结构、内容管理 |
| **键值型** | Redis | Key-Value | 缓存、会话、计数器 |
| **列族型** | Cassandra、HBase | 列簇 | 海量时序、大数据 |
| **图数据库** | Neo4j | 节点 + 关系 | 社交网络、推荐 |

---

## ⚖️ 二、NoSQL vs RDBMS

| 维度 | NoSQL | 关系型（RDBMS） |
| --- | --- | --- |
| 数据模型 | 灵活、动态 | 固定表结构 |
| 事务 | 弱（最终一致） | 强 ACID |
| 扩展 | 天然水平扩展 | 以垂直扩展为主 |
| 查询 | 各自方言 | SQL 标准 |
| 适用 | 高并发、海量、灵活结构 | 强一致性业务 |

> 💡 完整对比见 [RDBMS 指南](../RDBMS/index.md)。

---

## 🎯 三、何时选 NoSQL？

- 数据结构经常变化 → 文档型
- 需要超低延迟缓存 → 键值型
- 海量写入、按时间查询 → 列族型
- 强关系网络 → 图数据库
