# 🗄️ 关系型数据库（RDBMS）指南

关系型数据库是数据存储的"老大哥"，支撑着从银行系统到电商平台的绝大多数业务。本文介绍 RDBMS 的核心概念，以及主流数据库 MySQL 与 PostgreSQL 的选型。

---

## 🧠 一、什么是关系型数据库？

关系型数据库（Relational Database Management System，RDBMS）基于 **关系模型**，数据组织成 **表（Table）**，表由 **行（Row）** 和 **列（Column）** 组成，表之间通过 **主键/外键** 建立关联。

```
学生表 student                    成绩表 score
┌────┬──────┬────┐              ┌────────┬───────┐
│ id │ name │ age│              │ stu_id │ score │
├────┼──────┼────┤              ├────────┼───────┤
│ 1  │ 张三 │ 18 │              │ 1      │ 95    │
│ 2  │ 李四 │ 19 │              │ 1      │ 88    │
└────┴──────┴────┘              │ 2      │ 90    │
  主键 id ──────────────────→   └────────┴───────┘
                               外键 stu_id 引用 student.id
```

---

## 🔑 二、核心概念

| 概念 | 说明 |
| --- | --- |
| **表（Table）** | 数据的容器，由行和列组成 |
| **行（Row / Record）** | 一条记录 |
| **列（Column / Field）** | 一个字段 |
| **主键（Primary Key）** | 唯一标识一行的列，不可为空 |
| **外键（Foreign Key）** | 引用其他表主键的列，建立关联 |
| **索引（Index）** | 加速查询的数据结构（如 B+ 树） |
| **事务（Transaction）** | 一组要么全成功、要么全回滚的操作 |

**SQL（Structured Query Language）** 是与 RDBMS 交互的标准语言，四大类：

| 类别 | 作用 | 示例 |
| --- | --- | --- |
| DDL | 定义表结构 | `CREATE TABLE`、`ALTER` |
| DML | 增删改数据 | `INSERT`、`UPDATE`、`DELETE` |
| DQL | 查询数据 | `SELECT` |
| DCL | 权限控制 | `GRANT`、`REVOKE` |

## ⚖️ 三、RDBMS 与 NoSQL 对比

| 维度 | RDBMS（MySQL/PostgreSQL） | NoSQL（MongoDB/Redis） |
| --- | --- | --- |
| 数据模型 | 二维表，强结构 | 文档/键值/列族/图 |
| Schema | 固定，需预先定义 | 灵活，动态 |
| 事务 | 强 ACID | 弱（最终一致） |
| 扩展方式 | 垂直为主（主从/分库分表） | 水平扩展天然支持 |
| 查询 | SQL 标准 | 各自方言 |
| 适用 | 强一致性业务（订单、账务） | 海量数据、高并发、灵活结构 |

> 💡 实践：核心业务数据用 RDBMS 保证一致性，缓存/日志/灵活结构用 NoSQL。

## 🔀 四、MySQL vs PostgreSQL

| 维度 | MySQL | PostgreSQL |
| --- | --- | --- |
| 定位 | 轻量、高性能、易用 | 功能全面、标准兼容、扩展性强 |
| 性能 | 简单查询读性能好 | 复杂查询/大数据量更强 |
| 数据类型 | 基础类型 | JSONB、数组、区间、全文检索等丰富 |
| 扩展 | 分区表、复制 | CTE、窗口函数、物化视图、插件（PostGIS） |
| 生态 | 使用最广、文档最多 | 功能前沿、被"用 PG 解决一切"喜爱 |
| 选择 | 中小型应用、Web 常用 | 复杂查询、GIS、需要高级特性 |

## 🗺️ 五、学习路线

1. **SQL 基础**：增删改查、聚合、JOIN
2. **设计**：建表规范、范式、索引设计
3. **进阶**：事务与隔离级别、锁、执行计划
4. **高可用**：主从复制、读写分离、分库分表
5. **实践**：配合后端框架（MyBatis / JPA / Prisma）使用

---

## 🎯 六、小结

- RDBMS 用"表 + 关系"组织数据，SQL 是通用查询语言
- 核心特性：主键外键、索引、ACID 事务
- MySQL 与 PostgreSQL 各有优势，按业务场景选择
- 一致性敏感的业务数据首选 RDBMS
