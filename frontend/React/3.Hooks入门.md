# 🪝 React Hooks 入门

Hooks 让函数组件拥有状态和副作用能力，是现代 React 的核心。本文覆盖最常用的三个 Hooks。

---

## 🧠 一、Hooks 是什么？

在 React 16.8 之前，只有类组件能用状态。**Hooks 让函数组件也能用状态**，代码更简洁：

```jsx
// 类组件写法（旧）
class Counter extends React.Component {
  state = { count: 0 }
  render() {
    return <button onClick={() => this.setState({ count: this.state.count + 1 })}>
      {this.state.count}
    </button>
  }
}

// 函数组件 + Hooks（新）
function Counter() {
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{count}</button>
}
```

**Hooks 规则**：
- 只能在组件顶层调用（不能放在循环/条件/嵌套函数里）
- 只能从 React 函数组件或自定义 Hook 中调用
- 以 `use` 开头命名

## 🎯 二、useState：状态

```jsx
import { useState } from 'react'

function Counter() {
  const [count, setCount] = useState(0)   // 初始值 0

  return (
    <div>
      <p>计数：{count}</p>
      <button onClick={() => setCount(count + 1)}>加 1</button>
    </div>
  )
}
```

| 要点 | 说明 |
| --- | --- |
| `useState(初始值)` | 返回 `[当前值, 更新函数]` |
| `setCount(newValue)` | 更新状态并触发重渲染 |
| 更新函数形式 | `setCount(c => c + 1)` 基于上一次值 |

```jsx
// 对象状态
const [user, setUser] = useState({ name: '', age: 0 })
setUser({ ...user, name: '张三' })   // 注意要展开旧对象
```

## ⏳ 三、useEffect：副作用

处理数据请求、订阅、DOM 操作等副作用：

```jsx
import { useState, useEffect } from 'react'

function UserList() {
  const [users, setUsers] = useState([])
  const [loading, setLoading] = useState(true)

  useEffect(() => {
    // 组件挂载后执行
    fetch('/api/users')
      .then(res => res.json())
      .then(data => {
        setUsers(data)
        setLoading(false)
      })
  }, [])   // 依赖数组：空数组 = 只在挂载时执行一次

  if (loading) return <p>加载中...</p>
  return (
    <ul>
      {users.map(u => <li key={u.id}>{u.name}</li>)}
    </ul>
  )
}
```

**依赖数组控制执行时机**：

| 写法 | 执行时机 |
| --- | --- |
| `useEffect(fn)` | 每次渲染后都执行 |
| `useEffect(fn, [])` | 只在挂载时执行一次 |
| `useEffect(fn, [dep])` | `dep` 变化时执行 |

```jsx
// 清理函数：组件卸载时执行（取消订阅/计时器）
useEffect(() => {
  const timer = setInterval(() => tick(), 1000)
  return () => clearInterval(timer)   // 清理
}, [])
```

## 🌍 四、useContext：跨组件传数据

避免"props 层层传递"：

```jsx
// 1. 创建 Context
import { createContext, useContext, useState } from 'react'

const ThemeContext = createContext('light')

// 2. 父组件提供值
function App() {
  const [theme, setTheme] = useState('dark')
  return (
    <ThemeContext.Provider value={theme}>
      <Header />
      <Body />
    </ThemeContext.Provider>
  )
}

// 3. 任意后代直接读取
function Header() {
  const theme = useContext(ThemeContext)   // 'dark'
  return <header className={`theme-${theme}`}>标题</header>
}
```

> 💡 Context 适合主题、语言、用户信息等全局数据；频繁变化的 UI 状态用本地 state。

## 🧩 五、其他常用 Hooks

| Hook | 用途 |
| --- | --- |
| `useRef` | 引用 DOM / 保存不触发渲染的值 |
| `useMemo` | 缓存计算结果 |
| `useCallback` | 缓存函数引用 |
| `useReducer` | 复杂状态的 reducer 管理 |
| 自定义 Hook | `useXxx` 封装复用逻辑 |

```jsx
// useRef：聚焦输入框
function Login() {
  const inputRef = useRef(null)
  return <input ref={inputRef} onLoad={() => inputRef.current?.focus()} />
}

// 自定义 Hook
function useToggle(init = false) {
  const [on, setOn] = useState(init)
  return [on, () => setOn(v => !v)]
}
```

## 🎯 小结

- `useState` 管状态，`useEffect` 管副作用，`useContext` 管跨层传值
- 遵守 Hooks 规则：顶层调用、函数组件内、`use` 前缀
- 封装自定义 Hook 复用逻辑
