# 🧠 React 是什么？

## 📖 定义

React 是用于构建用户界面的 **JavaScript 库**，由 Meta（Facebook）开发，2013 年开源。它解决了"如何高效更新大型界面的状态"这一核心问题。

**与框架的区别**：React 本身只负责 **视图层**，路由、状态管理、构建工具需要搭配生态使用（React Router、Redux、Vite 等）。

---

## 🎯 四大核心概念

### 1. 组件化（Component）

UI 由独立的组件拼装而成，每个组件封装自己的结构和逻辑：

```jsx
function Button({ label, onClick }) {
  return <button onClick={onClick}>{label}</button>
}

function App() {
  return (
    <div>
      <Button label="保存" onClick={() => save()} />
      <Button label="取消" onClick={() => cancel()} />
    </div>
  )
}
```

**好处**：复用、隔离、可测试。

### 2. 声明式（Declarative）

你描述"界面应该长什么样"，React 负责如何更新：

```jsx
// 命令式：手动操作 DOM
// 声明式：描述状态 → UI
function Counter() {
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{count}</button>
}
```

状态变了，界面自动更新，**不需要手动操作 DOM**。

### 3. 单向数据流（One-way Data Flow）

数据从父组件流向子组件，清晰可预测：

```
App（数据源）
  └── Header（通过 props 接收）
  └── Body
        └── Card
```

子组件通过回调通知父组件修改数据，而不是直接改父组件状态。

### 4. 虚拟 DOM（Virtual DOM）

React 在内存中维护一棵虚拟树，状态变化时先对比新旧虚拟树，只更新差异部分：

```
状态变化 → 生成新虚拟树 → diff 对比 → 批量更新真实 DOM
```

**好处**：减少昂贵的真实 DOM 操作，提升性能。

---

## ⚡ React 的运行时

React 由两个包组成：

| 包 | 作用 |
| --- | --- |
| `react` | 核心：组件、Hooks、虚拟 DOM 机制 |
| `react-dom` | 浏览器渲染：把 React 树挂载到 DOM |

```jsx
import { createRoot } from 'react-dom/client'

createRoot(document.getElementById('root')).render(<App />)
```

---

## 🎯 小结

- React 是视图层库，核心是组件化 + 声明式
- 单向数据流让状态可预测
- 虚拟 DOM 优化更新性能
- 搭配路由、状态管理、构建工具形成完整方案
