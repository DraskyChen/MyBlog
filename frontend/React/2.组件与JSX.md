# 🧩 React 组件与 JSX

组件是 React 的基本单元，JSX 是编写组件的语法。本文覆盖函数组件、props、条件与列表渲染。

---

## 📝 一、JSX：JavaScript + HTML

JSX 允许在 JavaScript 里写类似 HTML 的语法，最终编译为普通 JS：

```jsx
const element = <h1>你好，世界！</h1>

// 嵌入 JavaScript 表达式：用 {}
const name = '张三'
const element = <p>你好，{name}！</p>

// 属性
const img = <img src={url} alt="图片" />
```

**规则**：
- 用 `{}` 嵌入表达式
- `class` 写 `className`
- 标签必须闭合，根节点包裹

```jsx
const el = (
  <div>
    <input className="input" />
  </div>
)
```

---

## 🧱 二、函数组件

现代 React 用函数定义组件：

```jsx
function Welcome() {
  return <h1>欢迎！</h1>
}

// 或箭头函数
const Welcome = () => <h1>欢迎！</h1>

// 使用
<Welcome />
```

组件名**必须大写开头**，React 以此区分组件和 HTML 标签。

---

## 📥 三、props：组件传参

数据从父组件传给子组件：

```jsx
function UserCard({ name, age }) {
  return (
    <div>
      <h3>{name}</h3>
      <p>年龄：{age}</p>
    </div>
  )
}

function App() {
  return (
    <div>
      <UserCard name="张三" age={18} />
      <UserCard name="李四" age={20} />
    </div>
  )
}
```

**props 的特点**：
- **只读**：子组件不能修改 props
- **单项**：只能父传子，子通过回调通知父

```jsx
// 子组件通知父组件
function Counter({ count, onIncrease }) {
  return <button onClick={onIncrease}>+1（当前 {count}）</button>
}

function App() {
  const [count, setCount] = useState(0)
  return <Counter count={count} onIncrease={() => setCount(count + 1)} />
}
```

## 🔀 四、条件渲染

```jsx
function Greeting({ isLogin }) {
  if (isLogin) {
    return <p>欢迎回来！</p>
  }
  return <p>请先登录</p>
}

// 三元表达式
function Status({ done }) {
  return <p>{done ? '已完成' : '进行中'}</p>
}

// 逻辑与：条件为真才渲染
{isLoading && <p>加载中...</p>}
```

## 📋 五、列表渲染

用 `map` 渲染数组，每个元素需要 `key`：

```jsx
function TodoList({ todos }) {
  return (
    <ul>
      {todos.map(todo => (
        <li key={todo.id}>{todo.text}</li>
      ))}
    </ul>
  )
}

const todos = [
  { id: 1, text: '学习 React' },
  { id: 2, text: '写个 Demo' },
]
```

> 💡 `key` 帮助 React 识别列表项的增删改，**不要用数组索引**作为 key。

## 🧩 六、组件组合

```jsx
function App() {
  return (
    <div className="app">
      <Header />
      <Main>
        <Card title="文章一" />
        <Card title="文章二" />
      </Main>
      <Footer />
    </div>
  )
}
```

组件通过组合（Composition）而非继承来复用 UI。

---

## 🎯 小结

- JSX 在 JS 中写 HTML，用 `{}` 嵌入表达式
- 函数组件是 React 现代写法，组件名大写
- props 单向传数据，只读不可改
- 条件渲染用 `if`/三元/`&&`，列表用 `map` + `key`
