# 🗺️ React 学习路线

React 生态丰富、演进快，本文给出一条从入门到工程化的清晰路径。

---

## 🪜 总路线图

```
①JS 基础 → ②React 核心 → ③Hooks → ④生态 → ⑤工程化 → ⑥进阶
```

---

## 📚 分阶段学习

### 阶段 1：JS 基础（必学）

React 是 JS 库，JS 基础不牢会处处卡壳。

- **本站配套**：[JavaScript](../JavaScript/index.md)（含 [ES6+](../JavaScript/ES6+.md)）
- 重点：箭头函数、解构、展开运算符、模块化、async/await

### 阶段 2：React 核心

- [React 是什么](./1.React是什么.md)：组件化、声明式、虚拟 DOM
- [组件与 JSX](./2.组件与JSX.md)：函数组件、props、条件与列表渲染

### 阶段 3：Hooks（重点）

- [Hooks 入门](./3.Hooks入门.md)：`useState` / `useEffect` / `useContext`
- 理解渲染机制与副作用处理

### 阶段 4：生态

| 工具 | 用途 |
| --- | --- |
| **React Router** | 前端路由（多页面跳转） |
| **状态管理** | Redux / Zustand / Jotai |
| **数据请求** | TanStack Query / SWR |
| **样式方案** | CSS Modules / Tailwind / styled-components |

### 阶段 5：工程化

- **脚手架**：Vite + React（`npm create vite@latest`）
- **TypeScript**：[TypeScript](../TypeScript/index.md) + React（类型安全）
- **测试**：Vitest + React Testing Library
- **部署**：Vercel / GitHub Pages

```bash
# 创建项目
npm create vite@latest my-app -- --template react-ts
```

### 阶段 6：进阶方向

| 方向 | 内容 |
| --- | --- |
| 服务端渲染 | Next.js（全栈 React 框架） |
| 微前端 | 大型应用拆分 |
| 性能优化 | memo、useMemo、代码分割 |
| 动画 | Framer Motion |

---

## 💡 学习建议

1. **先动手后深究**：`npm create vite` 建个项目，边写边学
2. **官方文档是圣经**：react.dev 质量极高
3. **Hooks 是重点**：现代 React 全部基于 Hooks 构建
4. **多写组件**：把 UI 拆成组件是 React 的核心能力

---

## 🎯 小结

- 主线：JS 基础 → React 核心 → Hooks → 生态 → 工程化
- Hooks（useState/useEffect）是掌握 React 的关键
- 用 Vite 脚手架 + 官方文档，动手写最快
