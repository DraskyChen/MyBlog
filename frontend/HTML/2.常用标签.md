# 🏷️ HTML 常用标签

本文按用途分类，介绍日常开发最常用的 HTML 标签。每一个都附示例，看完即可上手。

---

## 📄 一、文档与元信息

```html
<!DOCTYPE html>          <!-- 文档类型声明 -->
<html lang="zh-CN">       <!-- 根元素 -->
<head>                    <!-- 元信息区 -->
  <meta charset="UTF-8"> <!-- 字符编码 -->
  <meta name="description" content="页面描述，用于 SEO">
  <title>页面标题</title>
  <link rel="stylesheet" href="style.css"> <!-- 引入外部样式 -->
</head>
```

| 标签 | 作用 |
| --- | --- |
| `<!DOCTYPE html>` | 声明 HTML5 |
| `<meta>` | 元信息（编码、描述、viewport） |
| `<title>` | 浏览器标签页标题 |
| `<link>` | 引入外部 CSS 或图标 |
| `<style>` | 内嵌样式 |

---

## ✏️ 二、文本标签

```html
<h1>一级标题</h1>    <h2>二级标题</h2>    <h3>三级标题</h3>
<p>这是一个段落，用来放一段文字。</p>
<a href="https://example.com">超链接</a>
<span>行内文字</span>
<strong>加粗</strong>  <em>斜体</em>
<br>  <!-- 换行 -->
<hr>  <!-- 水平分隔线 -->
```

> 🚫 注意：`<h1>` 一个页面通常只用一个，标题层级要按顺序使用（h1 → h2 → h3），有利于 SEO。

---

## 📋 三、列表与表格

### 无序列表 / 有序列表

```html
<ul>
  <li>苹果</li>
  <li>香蕉</li>
</ul>

<ol>
  <li>第一步</li>
  <li>第二步</li>
</ol>
```

### 表格

```html
<table border="1">
  <tr>
    <th>姓名</th>
    <th>年龄</th>
  </tr>
  <tr>
    <td>张三</td>
    <td>18</td>
  </tr>
</table>
```

| 标签 | 含义 |
| --- | --- |
| `<table>` | 表格 |
| `<tr>` | 行 |
| `<th>` | 表头单元格（加粗居中） |
| `<td>` | 普通单元格 |

---

## 📝 四、表单标签

表单用于收集用户输入，是网页与用户交互的核心。

```html
<form action="/submit" method="post">
  <label for="name">用户名：</label>
  <input type="text" id="name" name="name" placeholder="请输入用户名">

  <label for="pwd">密码：</label>
  <input type="password" id="pwd" name="pwd">

  <label for="gender">性别：</label>
  <select id="gender" name="gender">
    <option value="male">男</option>
    <option value="female">女</option>
  </select>

  <textarea name="desc" rows="3" placeholder="个人简介"></textarea>

  <button type="submit">提交</button>
</form>
```

常用 `input` 类型：

| type | 用途 |
| --- | --- |
| `text` | 单行文本 |
| `password` | 密码（显示为圆点） |
| `email` | 邮箱（自动校验格式） |
| `number` | 数字 |
| `checkbox` | 复选框 |
| `radio` | 单选框 |
| `date` | 日期选择器 |
| `file` | 文件上传 |

## 🧭 五、语义化标签

HTML5 引入的语义化标签，让结构更清晰、更利于 SEO 和可访问性。

```html
<header>   页头（Logo、导航）</header>
<nav>      导航菜单</nav>
<main>     页面主体</main>
<section>  章节/区块</section>
<article>  独立文章</article>
<aside>    侧边栏</aside>
<footer>   页脚（版权信息）</footer>
```

> 💡 语义化标签的好处：代码可读性高、搜索引擎更容易理解页面结构、屏幕阅读器可以更好地为视障用户朗读。

---

## 🎯 六、小结

- 文档结构：`html` → `head`（元信息）+ `body`（内容）
- 文本、列表、表格、表单是四大常见内容类型
- 优先使用语义化标签（`header`/`main`/`footer`），少用无意义的 `div` 堆砌
