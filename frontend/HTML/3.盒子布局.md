# 📦 HTML 盒子布局

网页布局的核心是 **盒模型** 和 **弹性布局（Flex）**。理解了这两块，就掌握了现代网页排版的基石。

---

## 🧊 一、什么是盒模型？

HTML 中的每一个元素都可以看作一个 **盒子**，盒子从内到外包含四层：

```
┌─────────────────────────────┐
│         margin（外边距）      │
│  ┌───────────────────────┐  │
│  │    border（边框）        │  │
│  │  ┌─────────────────┐   │  │
│  │  │  padding（内边距） │   │  │
│  │  │  ┌───────────┐   │   │  │
│  │  │  │ content   │   │   │  │
│  │  │  │ 内容区域    │   │   │  │
│  │  │  └───────────┘   │   │  │
│  │  └─────────────────┘   │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

| 属性 | 含义 |
| --- | --- |
| `content` | 内容区（文字、图片） |
| `padding` | 内容到边框的距离（内边距） |
| `border` | 边框 |
| `margin` | 盒子到其他盒子的距离（外边距） |

**经典问题：`box-sizing: border-box` 有什么用？**

默认 `box-sizing: content-box` 时，`width` 只包含 content，实际占宽 = content + padding + border。

```css
/* 让 width 包含 padding 和 border，更符合直觉 */
* {
  box-sizing: border-box;
}
```

## 🎭 二、display 属性：元素的显示方式

| 值 | 特点 | 常见元素 |
| --- | --- | --- |
| `block` | 独占一行，可设宽高 | `div`、`p`、`h1` |
| `inline` | 同行排列，不可设宽高 | `span`、`a` |
| `inline-block` | 同行排列，可设宽高 | `img`、`button` |
| `flex` | 弹性容器 | `display: flex` |
| `none` | 不显示，不占空间 | `display: none` |

---

## 🎯 三、Flex 布局：现代布局的核心

给容器设置 `display: flex`，它的子元素会自动变成一行排列。

```css
.container {
  display: flex;
  /* 主轴方向：row 横向 / column 纵向 */
  flex-direction: row;
  /* 主轴对齐：center 居中 / space-between 两端对齐 */
  justify-content: space-between;
  /* 交叉轴对齐 */
  align-items: center;
  /* 是否换行 */
  flex-wrap: wrap;
}
```

### 容器常用属性

| 属性 | 作用 |
| --- | --- |
| `flex-direction` | 主轴方向（row / column） |
| `justify-content` | 主轴对齐方式 |
| `align-items` | 交叉轴对齐方式 |
| `flex-wrap` | 是否换行 |
| `gap` | 子元素间距 |

### 项目常用属性

| 属性 | 作用 |
| --- | --- |
| `flex` | 简写 `flex-grow flex-shrink flex-basis` |
| `flex: 1` | 等分剩余空间 |
| `align-self` | 单独覆盖交叉轴对齐 |
| `order` | 排序 |

**水平垂直居中（最常见的需求）：**

```css
.center {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

## 🔳 四、Grid 布局简介

Grid（网格）适合二维布局（行列同时控制），而 Flex 更适合一维（单行/单列）。

```css
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr; /* 三列等宽 */
  gap: 16px;                          /* 间距 */
}
```

## 🧩 五、实战：一个简单的导航栏

```html
<nav class="navbar">
  <a href="#">首页</a>
  <a href="#">关于</a>
  <a href="#">博客</a>
  <a href="#">联系</a>
</nav>
```

```css
.navbar {
  display: flex;
  gap: 20px;
  padding: 12px 24px;
  background: #333;
}

.navbar a {
  color: #fff;
  text-decoration: none;
}

.navbar a:hover {
  color: #41d1ff;
}
```

运行效果：一个横向排列、带悬停变色效果的导航栏。试着把 `flex-direction` 改成 `column`，导航栏就变成竖排了。

---

## 🎯 六、小结

- 每个元素都是一个盒子：content → padding → border → margin
- 默认 `box-sizing` 是 content-box，推荐统一为 `border-box`
- Flex 是单行/单列布局首选，居中三件套要牢记
- Grid 适合二维网格布局
