# ⚡ HTML 快速入门

本文带你 10 分钟写出第一个网页，并了解日常开发最常用的浏览器工具。

---

## 🖥️ 一、环境准备

写 HTML 只需要两样东西：

1. **浏览器**：Chrome / Edge / Firefox 任选其一
2. **文本编辑器**：推荐 VSCode，安装后搜索安装扩展 `Live Server`（可让浏览器自动刷新）

**创建你的工作目录**：

```bash
mkdir my-first-page && cd my-first-page
touch index.html
```

用 VSCode 打开 `index.html`，在编辑器里输入 `!` 并按 `Tab`，会自动生成 HTML5 模板。

---

## ✍️ 二、第一个页面

把下面的代码粘贴到 `index.html`：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>我的第一个网页</title>
</head>
<body>
  <h1>你好，世界！👋</h1>
  <p>这是用 HTML 写的第一行内容。</p>
  <a href="https://www.example.com">点击访问示例网站</a>
</body>
</html>
```

**在浏览器中打开**：双击 `index.html`，或者右键 → 用浏览器打开。

你会看到一个包含标题、段落和链接的页面。

---

## 🧰 三、常用浏览器工具（DevTools）

按 `F12`（Mac 上是 `Cmd + Option + I`）打开 **开发者工具**，这是前端开发最重要的工具。

| 面板 | 作用 |
| --- | --- |
| **Elements** | 查看和实时修改页面 HTML/CSS |
| **Console** | 查看报错、运行 JavaScript |
| **Network** | 查看网络请求、加载性能 |
| **Sources** | 断点调试 JavaScript |
| **Application** | 查看 Cookie、LocalStorage 等 |

**练一练**：在 Elements 面板选中 `<h1>`，右侧可以直接修改文字，页面上会实时变化——这就是 DevTools 的即时预览能力。

---

## 🐛 四、常见问题

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| 中文显示为乱码 | 缺少 `charset` 声明 | 在 `<head>` 加 `<meta charset="UTF-8">` |
| 修改了代码页面没变 | 浏览器缓存 | 按 `Cmd + Shift + R` 强制刷新 |
| 标签没有效果 | 标签未闭合 | 检查是否漏了 `</p>` 这类闭合标签 |
| 链接点了没反应 | href 写错 | 检查 URL 或是否拼错标签名 |

---

## 🎯 五、小结

- 用 `!` + Tab 快速生成 HTML5 模板
- `head` 放元信息，`body` 放可见内容
- DevTools 是前端必备工具，多用它调试
- 中文页面务必声明 `<meta charset="UTF-8">`
