# 📖 JavaScript 基础语法

本文覆盖 JS 最核心的基础语法：变量、类型、运算符、流程控制、函数，以及数组和对象。全部示例可直接在浏览器控制台（F12）运行。

---

## 🏷️ 一、变量：var / let / const

```js
var old = '旧式声明'    // 有变量提升，函数作用域，尽量不用
let count = 0          // 块级作用域，可重新赋值
const PI = 3.14        // 块级作用域，声明后不可重新赋值
```

| 关键字 | 作用域 | 可重新赋值 | 提升 |
| --- | --- | --- | --- |
| `var` | 函数级 | ✅ | ✅（值为 undefined） |
| `let` | 块级 `{}` | ✅ | ❌（暂时性死区） |
| `const` | 块级 `{}` | ❌ | ❌ |

> 💡 现代规范：**默认用 `const`，需要重新赋值时才用 `let`**。

## 🎲 二、数据类型

JS 有 7 种基本类型 + 1 种引用类型：

```js
typeof 42            // 'number'
typeof 'hello'       // 'string'
typeof true          // 'boolean'
typeof undefined     // 'undefined'
typeof null          // 'object'   ← 历史遗留 bug！
typeof Symbol()      // 'symbol'
typeof 123n          // 'bigint'
typeof {}            // 'object'
```

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| `number` | 数字（含整数/浮点/NaN/Infinity） | `3.14`、`NaN` |
| `string` | 字符串 | `'a'`、`"b"`、`` `c` `` |
| `boolean` | 布尔值 | `true` / `false` |
| `undefined` | 未定义 | 声明未赋值 |
| `null` | 空值 | 主动置空 |
| `object` | 对象/数组/函数 | `{a:1}`、`[1,2]` |
| `symbol` / `bigint` | 符号 / 大整数 | `Symbol()`、`10n` |

### 类型转换

```js
Number('42')   // 42
parseInt('42px') // 42
String(42)     // '42'
Boolean(0)     // false；空字符串、null、undefined、NaN 都是 falsy
```

## ➕ 三、运算符

```js
// 算术
1 + 2    // 3
'1' + 2  // '12'  ← 字符串拼接优先

// 比较
3 > 2     // true
'3' == 3  // true  松散相等（会转换类型，慎用）
'3' === 3 // false 严格相等（推荐）
3 !== 4   // true

// 逻辑
true && false // false
true || false // true
!true         // false
```

## 🔀 四、流程控制

### 条件判断

```js
if (score >= 60) {
  console.log('及格')
} else if (score >= 90) {
  console.log('优秀')
} else {
  console.log('不及格')
}

// switch
switch (day) {
  case 1: console.log('周一'); break
  default: console.log('其他')
}
```

### 循环

```js
// for
for (let i = 0; i < 5; i++) {
  console.log(i)
}

// while
let i = 0
while (i < 5) { i++ }

// for...of 遍历数组
for (const item of [1, 2, 3]) {
  console.log(item)
}
```

## 🧮 五、函数

```js
// 函数声明
function add(a, b) {
  return a + b
}

// 函数表达式
const sub = function (a, b) {
  return a - b
}

// 箭头函数（ES6）
const mul = (a, b) => a * b

console.log(add(1, 2), sub(5, 3), mul(2, 3)) // 3 2 6
```

| 写法 | 特点 |
| --- | --- |
| 函数声明 | 有提升，可在声明前调用 |
| 函数表达式 | 无提升，赋值后才可用 |
| 箭头函数 | 无自己的 `this`，适合回调 |

## 🗂️ 六、数组与对象

```js
// 数组
const arr = [1, 2, 3]
arr.push(4)          // [1,2,3,4]
arr.pop()            // 移除末尾
arr[0]               // 1
arr.length           // 3
arr.map(n => n * 2)  // [2,4,6] 映射
arr.filter(n => n > 1) // [2,3] 过滤

// 对象
const user = { name: '张三', age: 18 }
user.name       // '张三'
user['age']     // 18
user.email = 'a@b.com'  // 添加属性
```

---

## 🎯 七、小结

- `const` / `let` 代替 `var`，`===` 代替 `==`
- 7 种基本类型，`typeof null === 'object'` 是历史 bug
- 箭头函数简洁且无自己的 `this`
- 数组的 `map` / `filter` 是高频方法，务必熟练
