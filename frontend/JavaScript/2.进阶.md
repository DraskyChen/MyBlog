# 🚀 JavaScript 进阶

掌握基础语法后，这篇带你理解 JS 的核心机制：作用域、闭包、`this`、原型链、事件循环、模块化与异步处理。这些是面试重点，也是写复杂应用的必备。

---

## 🌍 一、作用域与闭包

### 作用域

- **全局作用域**：任何地方可访问
- **函数作用域**：`var` 声明
- **块级作用域**：`let` / `const`，限制在 `{}` 内

```js
function outer() {
  let x = 10
  function inner() {
    console.log(x) // 可以访问 outer 的 x
  }
  inner()
}
```

### 闭包

**闭包 = 函数 + 它定义时所在作用域的引用**。内部函数即使在外层函数执行结束后，仍能访问外层变量。

```js
function counter() {
  let count = 0
  return function () {
    return ++count
  }
}

const c = counter()
c() // 1
c() // 2  ← count 被"记住"了
```

> 💡 闭包用途：封装私有变量、柯里化、防抖/节流。

## 👉 二、this 的指向

`this` 在调用时决定，与定义位置无关：

| 调用方式 | this 指向 |
| --- | --- |
| 普通函数调用 | `window`（严格模式 `undefined`） |
| 对象方法调用 | 该对象 |
| `new` 调用 | 新创建的实例 |
| `call`/`apply`/`bind` | 手动指定的对象 |
| 箭头函数 | 定义时外层作用域的 `this` |

```js
const obj = {
  name: 'obj',
  getName() {
    console.log(this.name) // obj
  },
  arrow: () => {
    console.log(this.name) // 外层 this（window）
  }
}
```

> 💡 箭头函数没有自己的 `this`，所以回调里想保留外层 `this` 时用它最省心。

## 🧬 三、原型与原型链

每个对象都有一个隐式原型 `__proto__`（指向构造函数的 `prototype`），查找属性时沿原型链向上找。

```js
function Person(name) {
  this.name = name
}
Person.prototype.greet = function () {
  console.log(`你好，${this.name}`)
}

const p = new Person('张三')
p.greet() // 你好，张三
p.toString() // 沿原型链找到 Object.prototype
```

> 💡 类（class）本质是构造函数的语法糖，底层仍是原型链。

## ⏳ 四、事件循环与宏/微任务

JS 是单线程，靠 **事件循环** 处理异步：

```
执行栈（同步任务）
   ↓ 遇到异步交给 Web API
任务队列：宏任务（setTimeout）| 微任务（Promise）
事件循环：栈空 → 先清空所有微任务 → 取一个宏任务 → 循环
```

```js
console.log(1)                 // 1（同步）
setTimeout(() => console.log(3), 0) // 宏任务
Promise.resolve().then(() => console.log(2)) // 微任务
// 输出顺序：1 → 2 → 3
```

> 💡 微任务（Promise.then / queueMicrotask）优先于宏任务（setTimeout / setInterval）。

## 📦 五、模块化

现代项目用 ES Module（ESM）：

```js
// math.js
export const add = (a, b) => a + b
export default function hello() { console.log('hi') }

// main.js
import hello, { add } from './math.js'
hello()
console.log(add(1, 2))
```

CommonJS（Node 传统写法）：

```js
// math.js
module.exports = { add: (a, b) => a + b }
// main.js
const { add } = require('./math.js')
```

## 🧯 六、异常处理与 Promise 基础

```js
// try-catch 同步异常
try {
  throw new Error('出错了')
} catch (e) {
  console.log(e.message)
} finally {
  console.log('总会执行')
}

// Promise 处理异步
fetch('/api/user')
  .then(res => res.json())
  .then(data => console.log(data))
  .catch(err => console.error(err))
```

> 💡 `async/await` 是 Promise 的语法糖，见 [ES6+](./ES6+.md)。

---

## 🎯 七、小结

- 闭包让函数记住外层变量，是 JS 的重要特性
- `this` 看调用方式，箭头函数绑定定义时的外层 `this`
- 原型链是 JS 面向对象的底层机制
- 事件循环：微任务先于宏任务
- 异步三件套：`Promise` → `async/await` → `fetch`
