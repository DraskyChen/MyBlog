# 📥 CSS 的引入方式

## 🧩 三种写法

| 方式 | 写法 | 适用场景 |
| --- | --- | --- |
| **外部样式** | `<link rel="stylesheet" href="style.css">` | ✅ 推荐，多页面复用 |
| **内嵌样式** | `<style>...</style>` 放 `<head>` 中 | 单页面少量样式 |
| **行内样式** | `<p style="color:red">` | ❌ 尽量避免，难维护 |

### 1. 外部样式（推荐）

把 CSS 写在一个独立的 `.css` 文件里，用 `<link>` 引入：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <!-- 引入外部样式表 -->
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>标题</h1>
</body>
</html>
```

```css
/* style.css */
h1 {
  color: #41d1ff;
  font-size: 32px;
}
```

**优点**：多页面共享、浏览器可缓存、与 HTML 分离易维护。

### 2. 内嵌样式

把 CSS 写在 HTML 的 `<style>` 标签里：

```html
<head>
  <style>
    h1 { color: red; }
  </style>
</head>
```

**适用**：单个页面的少量样式，或演示代码时。

### 3. 行内样式

直接在标签上写 `style` 属性：

```html
<p style="color: red; font-size: 18px;">这段文字是红色的</p>
```

**缺点**：无法复用、优先级高难覆盖、与结构耦合，**生产环境应避免**。

---

## ⚖️ 优先级规则

当多种方式作用于同一元素时，按 **优先级（specificity）** 决定最终样式：

```
行内样式（1000）
  > ID 选择器（100）
  > 类/伪类选择器（10）
  > 标签选择器（1）
  > 通配符（0）
```

```css
/* 优先级：行内 > #title > .highlight > p > * */
#title { color: red; }
.highlight { color: blue; }
p { color: green; }
* { color: black; }
```

> 💡 同优先级下，**后写的覆盖先写的**（层叠）。

---

## 🎯 小结

- 首选外部样式（`<link>`），其次内嵌，避免行内
- 优先级：行内 > ID > 类 > 标签 > 通配符
- 层叠规则：同优先级时后写的生效
