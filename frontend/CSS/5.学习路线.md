# 🗺️ CSS 学习路线

CSS 入门容易、精通难。本文给出从基础到工程化的清晰路径。

---

## 🪜 总路线图

```
①基础语法 → ②布局 → ③视觉进阶 → ④响应式 → ⑤动画 → ⑥工程化
```

---

## 📚 分阶段学习

### 阶段 1：基础语法

掌握怎么"描述样式"。

- [引入方式](./1.引入方式.md)：link / style / 内联
- [选择器](./2.选择器.md)：类、ID、组合、伪类
- 颜色、字体、文本排版

### 阶段 2：布局（重点）

排版的基石，投入最多时间。

- [盒模型与布局](./3.盒模型与布局.md)：content/padding/border/margin
- Flex：单行排列、居中
- Grid：二维网格

### 阶段 3：视觉进阶

- 背景、渐变、阴影
- 字体排版、间距节奏
- CSS 变量（自定义属性）

```css
:root {
  --brand-color: #41d1ff;
}
.button {
  background: var(--brand-color);
}
```

### 阶段 4：响应式

- [响应式设计](./4.响应式设计.md)：媒体查询、相对单位
- 移动优先（Mobile First）写法

### 阶段 5：动画

- `transition`：状态过渡
- `transform`：位移/缩放/旋转
- `animation` + keyframes：复杂动画

```css
.card:hover {
  transform: translateY(-4px);
  transition: transform 0.2s ease;
}
```

### 阶段 6：工程化

| 技术 | 作用 |
| --- | --- |
| **CSS 变量** | 主题化、设计令牌 |
| **BEM 命名** | `.block__element--modifier`，避免冲突 |
| **Sass/SCSS** | 嵌套、混合、函数 |
| **CSS Modules** | 组件级样式隔离 |
| **Tailwind** | 原子化 CSS，现代主流选择 |

---

## 🛠️ 工具推荐

| 工具 | 用途 |
| --- | --- |
| 浏览器 DevTools | 实时调试样式（Elements 面板） |
| MDN CSS 文档 | 权威参考 |
| Can I Use | 检查特性兼容性 |
| CodePen | 在线练习与分享 |

---

## 💡 学习建议

1. **动手改样式**：在 DevTools 里改颜色、调间距，立刻看到反馈
2. **先 Flex 后 Grid**：Flex 解决 80% 的日常布局
3. **模仿好网站**：看到喜欢的布局，用 DevTools 逆向分析
4. **不背属性**：理解盒模型和文档流，属性自然就记住了

---

## 🎯 小结

- 主线：基础 → 布局 → 响应式 → 动画 → 工程化
- 布局（Flex/Grid）和响应式是重点
- 多用 DevTools 动手调试，进步最快
