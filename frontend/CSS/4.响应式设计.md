# 📱 CSS 响应式设计

响应式设计让同一套代码在手机、平板、桌面不同屏幕下都表现良好。核心工具是 **媒体查询（Media Query）**。

---

## 🧠 一、为什么需要响应式？

| 设备 | 常见宽度 | 特点 |
| --- | --- | --- |
| 手机 | 375px | 竖屏窄视口 |
| 平板 | 768px | 中等宽度 |
| 桌面 | 1280px+ | 宽视口 |

没有响应式，手机上看桌面版网页需要横向滚动，体验极差。

---

## 📐 二、视口声明（viewport）

响应式的前提是让页面宽度跟随设备：

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

- `width=device-width`：页面宽度 = 设备宽度
- `initial-scale=1.0`：初始缩放比例为 1

> ⚠️ 没有这行声明，手机浏览器会用 980px 的桌面宽度渲染页面。

---

## 🎚️ 三、媒体查询

### 基础用法

```css
/* 默认（桌面）样式 */
.card { width: 30%; }

/* 屏幕宽度 ≤ 768px 时生效 */
@media (max-width: 768px) {
  .card { width: 100%; }
}
```

### 常用断点

```css
/* 小屏手机 */
@media (max-width: 576px) { }

/* 手机/平板 */
@media (max-width: 768px) { }

/* 平板/小桌面 */
@media (max-width: 992px) { }

/* 桌面（可选） */
@media (min-width: 1200px) { }
```

### 逻辑组合

```css
/* 横屏手机 */
@media (max-width: 768px) and (orientation: landscape) { }

/* 高清屏 */
@media (min-resolution: 2dppx) { }
```

---

## 📏 四、相对单位

响应式布局应少用固定 `px`，多用相对单位：

| 单位 | 含义 | 特点 |
| --- | --- | --- |
| `%` | 父容器百分比 | 随父元素变化 |
| `rem` | 根元素（html）字号倍数 | 全站统一缩放 |
| `em` | 当前元素字号倍数 | 相对当前元素 |
| `vw` / `vh` | 视口宽/高的 1% | 随视口变化 |
| `clamp()` | 三值钳制 | 自动限幅 |

```css
/* rem 方案：html 字号随屏幕变化，全站等比缩放 */
html { font-size: 16px; }
@media (max-width: 768px) {
  html { font-size: 14px; }
}

h1 { font-size: 2rem; }  /* 32px / 28px */

/* clamp：字号在 16px~24px 之间自适应 */
.title { font-size: clamp(1rem, 2.5vw, 1.5rem); }
```

---

## 🧩 五、弹性布局配合

响应式 = 媒体查询 + 弹性布局：

```css
/* 桌面：三列 */
.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

/* 平板：两列 */
@media (max-width: 992px) {
  .cards { grid-template-columns: repeat(2, 1fr); }
}

/* 手机：一列 */
@media (max-width: 576px) {
  .cards { grid-template-columns: 1fr; }
}
```

用 `auto-fit` 可以完全免去断点：

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
}
```

---

## 🎯 六、小结

- 响应式核心：viewport 声明 + 媒体查询
- 断点按内容设计，常用 576/768/992px
- 多用相对单位（rem、%、clamp），少用固定 px
- Flex/Grid 弹性布局 + 媒体查询组合最实用
