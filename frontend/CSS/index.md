# 🎨 CSS 入门指南

CSS（Cascading Style Sheets，层叠样式表）负责网页的 **外观**：颜色、字体、间距、布局、动画。如果说 HTML 是骨架，CSS 就是装修。

## 💡 快速认识 CSS

CSS 通过 **选择器** 选中页面元素，再用 **属性/值** 描述它的样式：

```css
/* 选中所有 <p> 标签 */
p {
  color: red;        /* 文字颜色 */
  font-size: 16px;   /* 字号 */
}
```

- **选择器** `p`：选中要美化的元素
- **声明块** `{ ... }`：`属性: 值;` 的集合

CSS 的核心能力：

| 能力 | 说明 |
| --- | --- |
| 颜色与字体 | 文字、背景、排版 |
| 盒模型 | 每个元素的尺寸与间距 |
| 布局 | Flex、Grid 现代布局 |
| 响应式 | 适配手机/平板/桌面 |
| 动画 | transition、animation |
