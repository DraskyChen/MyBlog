# 🎯 CSS 选择器

选择器决定"哪些元素会被这条样式命中"。掌握选择器，是写好 CSS 的第一步。

---

## 🧱 一、基础选择器

| 选择器 | 写法 | 含义 | 优先级 |
| --- | --- | --- | --- |
| 标签 | `p` | 所有 `<p>` | 1 |
| 类 | `.btn` | `class="btn"` 的元素 | 10 |
| ID | `#header` | `id="header"` 的元素（页面唯一） | 100 |
| 通配符 | `*` | 所有元素 | 0 |

```css
/* 标签选择器：所有段落红色 */
p { color: red; }

/* 类选择器：所有 .warning 元素加粗 */
.warning { font-weight: bold; }

/* ID 选择器：id 为 header 的元素 */
#header { background: #f5f5f5; }

/* 通配符：reset 边距 */
* { margin: 0; padding: 0; }
```

> 💡 **多用类选择器**。ID 应留给 JS 钩子；标签选择器易误伤；`*` 慎用。

---

## 🧬 二、组合选择器

| 选择器 | 写法 | 含义 |
| --- | --- | --- |
| 后代 | `nav a` | `nav` 内的所有 `a`（任意层级） |
| 直接子元素 | `.parent > .child` | 仅直接子级 |
| 相邻兄弟 | `h2 + p` | 紧跟在 h2 后的 p |
| 通用兄弟 | `h2 ~ p` | h2 之后的所有 p |
| 分组 | `h1, h2, h3` | 多个选择器共用样式 |

```css
/* 后代：导航内所有链接 */
nav a { text-decoration: none; }

/* 直接子元素：仅 list 的直接子 li */
.menu > li { border-bottom: 1px solid #eee; }

/* 分组：统一标题间距 */
h1, h2, h3 { line-height: 1.4; }
```

## ✨ 三、属性与伪类

### 属性选择器

```css
/* 所有 type=text 的输入框 */
input[type="text"] { border: 1px solid #ccc; }

/* class 以 btn- 开头 */
[class^="btn-"] { cursor: pointer; }
```

### 伪类（:）

| 伪类 | 含义 |
| --- | --- |
| `:hover` | 鼠标悬停 |
| `:focus` | 获得焦点（输入框） |
| `:first-child` / `:last-child` | 第一个 / 最后一个子元素 |
| `:nth-child(2)` | 第 2 个子元素 |
| `:not(.x)` | 排除 .x |

```css
/* 悬停变色 */
a:hover { color: #41d1ff; }

/* 表格隔行变色 */
tr:nth-child(even) { background: #f9f9f9; }

/* 排除类 */
.item:not(.active) { opacity: 0.5; }
```

### 伪元素（::）

```css
/* 首行 */
p::first-line { font-weight: bold; }

/* 插入内容 */
a::after { content: " ↗"; }

/* 占位符 */
input::placeholder { color: #999; }
```

---

## 🎯 四、小结

- 基础四件套：标签 / 类 / ID / 通配符
- 组合选择器实现精准定位（后代、子级、兄弟）
- 伪类 `:` 管状态，伪元素 `::` 管内容
- 实战推荐：**类选择器为主**，伪类处理交互状态
