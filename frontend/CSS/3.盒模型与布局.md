# 🧊 CSS 盒模型与布局

网页排版的核心是 **盒模型** 与 **Flex/Grid 布局**。理解这两块，就掌握了现代 CSS 排版的基石。

---

## 📦 一、盒模型

HTML 中的每个元素都可以看作一个 **盒子**，从内到外四层：

```
┌─────────────────────────────┐
│         margin（外边距）      │
│  ┌───────────────────────┐  │
│  │    border（边框）        │  │
│  │  ┌─────────────────┐   │  │
│  │  │  padding（内边距） │   │  │
│  │  │  ┌───────────┐   │   │  │
│  │  │  │ content   │   │   │  │
│  │  │  │ 内容区域    │   │   │  │
│  │  │  └───────────┘   │   │  │
│  │  └─────────────────┘   │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

| 属性 | 含义 |
| --- | --- |
| `content` | 内容区（文字、图片） |
| `padding` | 内容到边框的距离（内边距） |
| `border` | 边框 |
| `margin` | 盒子到其他盒子的距离（外边距） |

### box-sizing 经典问题

默认 `box-sizing: content-box` 时，`width` 只算 content，实际占宽还要加 padding 和 border：

```css
/* 让 width 包含 padding 和 border，更符合直觉 */
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

## 🎭 二、display：元素的显示方式

| 值 | 特点 | 常见元素 |
| --- | --- | --- |
| `block` | 独占一行，可设宽高 | `div`、`p`、`h1` |
| `inline` | 同行排列，不可设宽高 | `span`、`a` |
| `inline-block` | 同行排列，可设宽高 | `img`、`button` |
| `flex` | 弹性容器 | `display: flex` |
| `grid` | 网格容器 | `display: grid` |
| `none` | 不显示，不占空间 | `display: none` |

```css
/* inline 无法设宽高，改成 inline-block 即可 */
.icon { display: inline-block; width: 24px; height: 24px; }
```

## 🎯 三、Flex 布局（一维）

给容器设 `display: flex`，子元素自动沿主轴排列：

```css
.container {
  display: flex;
  flex-direction: row;         /* row 横向 / column 纵向 */
  justify-content: center;     /* 主轴对齐 */
  align-items: center;         /* 交叉轴对齐 */
  flex-wrap: wrap;             /* 是否换行 */
  gap: 16px;                   /* 子元素间距 */
}
```

**容器属性：**

| 属性 | 作用 |
| --- | --- |
| `flex-direction` | 主轴方向（row / column） |
| `justify-content` | 主轴对齐（center / space-between / space-around） |
| `align-items` | 交叉轴对齐（center / stretch / flex-start） |
| `flex-wrap` | 是否换行 |
| `gap` | 子元素间距 |

**项目属性：**

| 属性 | 作用 |
| --- | --- |
| `flex: 1` | 等分剩余空间 |
| `flex-grow` / `flex-shrink` | 放大 / 缩小比例 |
| `align-self` | 单独覆盖交叉轴对齐 |
| `order` | 排列顺序 |

**水平垂直居中（最高频需求）：**

```css
.center {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

---

## 🔳 四、Grid 布局（二维）

Grid 适合同时控制行与列的二维布局：

```css
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr; /* 三列等宽 */
  gap: 16px;                          /* 行列间距 */
}
```

**Flex vs Grid 怎么选：**

| 场景 | 选择 |
| --- | --- |
| 单行/单列排列 | Flex |
| 网格状卡片（行列同时控制） | Grid |
| 混合 | Grid 定整体，Flex 处理行内细节 |

## 🧩 五、实战：导航栏 + 卡片网格

```html
<nav class="navbar">
  <a href="#">首页</a>
  <a href="#">关于</a>
  <a href="#">博客</a>
</nav>

<div class="cards">
  <div class="card">卡片 1</div>
  <div class="card">卡片 2</div>
  <div class="card">卡片 3</div>
</div>
```

```css
/* 导航栏：Flex 横排 */
.navbar {
  display: flex;
  gap: 20px;
  padding: 12px 24px;
  background: #333;
}
.navbar a { color: #fff; text-decoration: none; }
.navbar a:hover { color: #41d1ff; }

/* 卡片网格：Grid 三列 */
.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
.card {
  padding: 24px;
  border: 1px solid #e5e5e5;
  border-radius: 8px;
}
```

## 🎯 六、小结

- 每个元素是盒子：content → padding → border → margin
- 统一 `box-sizing: border-box` 让宽高计算更直观
- Flex 管一维排列，Grid 管二维网格
- 居中三件套 `flex + justify-content + align-items` 要牢记
