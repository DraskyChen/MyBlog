# 📦 Git 版本控制

Git 是当今最流行的分布式版本控制系统，几乎所有开发协作都离不开它。

---

## 📚 目录导航

- [📝 Git 学习笔记](./Git学习笔记.md) —— 核心概念、常用命令、协作流程

---

## 🧠 一、为什么用 Git？

| 能力 | 说明 |
| --- | --- |
| 版本历史 | 记录每次修改，可随时回滚 |
| 分支协作 | 多人并行开发互不干扰 |
| 代码审查 | PR/MR 流程提升代码质量 |
| 分布式 | 本地仓库完整，离线可用 |

---

## 🗺️ 学习要点

1. **工作区三状态**：工作区 → 暂存区 → 本地仓库
2. **核心命令**：`add` / `commit` / `push` / `pull`
3. **分支操作**：`branch` / `checkout` / `merge`
4. **团队协作**：`clone` / `remote` / `PR`
5. **进阶**：`rebase` / `stash` / `cherry-pick`

> 💡 完整命令与流程图见 [Git 学习笔记](./Git学习笔记.md)。
