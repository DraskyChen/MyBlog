# 🌐 Web 服务器与反向代理

Web 服务器负责接收 HTTP 请求并返回响应。Nginx 以其 **高性能** 和 **灵活的反向代理/负载均衡** 能力，成为现代服务端架构的标配。

## 🧠 一、Web 服务器是什么？

```
用户浏览器 ──HTTP 请求──> Web 服务器 ──> 返回页面/资源
```

| 服务器 | 特点 |
| --- | --- |
| **Nginx** | 高性能、事件驱动、反向代理强 |
| Apache | 老牌、模块丰富、配置灵活 |
| Caddy | 自动 HTTPS，配置极简 |

---

## 🔄 二、反向代理与正向代理

| 类型 | 作用 |
| --- | --- |
| **正向代理** | 代理客户端（如访问外网的代理服务器） |
| **反向代理** | 代理服务端（隐藏后端，分发请求到多台服务器） |

```
反向代理场景：
用户 ──> Nginx（80 端口）──> 前端静态资源
                     └──> 后端 API（127.0.0.1:8080）
                     └──> 静态图片（另一个服务）
```

---

## 🗺️ 学习要点

1. **静态资源服务**：托管前端构建产物
2. **反向代理**：`proxy_pass` 转发请求
3. **负载均衡**：upstream 分发到多台后端
4. **HTTPS**：证书配置与自动跳转
5. **其他**：缓存、限流、日志
